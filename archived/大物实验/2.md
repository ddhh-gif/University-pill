# 共振抑制的应用


## 一、引言

在工程实践中,共振是一个反复出现的核心问题。当外部激励的频率接近系统固有频率时,稳态响应的振幅会被放大约 $Q \approx 1/(2\zeta)$ 倍,其中 $\zeta$ 为阻尼比。这种放大在不同的工程场景中会带来不同后果:对结构而言意味着疲劳寿命的迅速衰减乃至断裂;对旋转机械而言意味着轴承负荷急剧上升;对控制系统而言意味着伪信号污染反馈环路,进而引发自激振荡;对精密测量而言则意味着信噪比塌陷。从 Tacoma Narrows 桥的著名事故,到无人机机架与桨叶基频耦合,再到光学平台对地面微振动的敏感,共振抑制的工程意义贯穿了从大型土木结构到微机电系统的全部尺度。

应对共振的策略可以归结为三类:其一是"避开",通过改变系统参数使固有频率远离激励频率;其二是"压低",通过引入额外的能量耗散或反馈力降低共振峰高度;其三是"抠掉",在信号或指令层面消除共振的可观测影响,从而避免它进入控制回路或被放大。本文以同一个二阶受迫振动模型为基础,系统梳理工程中七种主流的共振抑制方法,统一其数学形式,并在最后从干预节点与能量需求两个维度进行横向比较。
**关键词: 共振抑制 谐振 被动方法 主动方法 输入整形**

## 二、基础模型

为建立后续讨论的统一框架,本节给出单自由度受迫振动系统的标准方程及其频域响应。考虑一个质量为 $m$、阻尼系数为 $c$、刚度为 $k$ 的线性系统,受到简谐激励 $F(t) = F_0\cos(\omega t)$ 的作用,其动力学方程为:

$$m\ddot{x} + c\dot{x} + kx = F_0\cos(\omega t)$$

定义无阻尼固有频率 $\omega_0$、阻尼比 $\zeta$ 与品质因数 $Q$ 如下:

$$\omega_0 = \sqrt{\frac{k}{m}}, \qquad \zeta = \frac{c}{2\sqrt{mk}}, \qquad Q = \frac{1}{2\zeta}$$

引入归一化频率 $r = \omega/\omega_0$,可写出系统位移对激励力的频率响应函数模值:

$$|H(j\omega)| = \frac{1/k}{\sqrt{(1-r^2)^2 + (2\zeta r)^2}}$$

对该表达式关于 $r$ 求极值,可得共振峰位置:

$$\omega_r = \omega_0\sqrt{1-2\zeta^2}$$

当 $\zeta \ll 1$ 时,$\omega_r \approx \omega_0$,共振峰高度近似为 $Q/k$。这一表达式清晰地揭示了共振的本质:在轻阻尼系统中,响应放大倍数与阻尼比成反比,而阻尼比通常很小,因此共振放大可能达到数十甚至数百倍。

这一模型虽然简单,但具有重要的统一性意义:本文后续介绍的所有七种抑制方法,本质上都是对该方程不同变量(质量、刚度、阻尼、激励、反馈)的"动手",或是在该方程的输入或输出端做信号处理。理解这一点,有助于在工程选型时跳出方法名词,直接回到物理本质做判断。

## 三、被动抑制类

被动抑制是指在不引入外部能量、传感器或控制器的前提下,通过结构参数设计降低共振响应的方法。其优点是可靠性高、无需供电、不会因控制失效而发散;缺点是带宽固定、缺乏对工况变化的适应能力。

### 1)增大阻尼(改 c)

最直接的思路是增大系统的阻尼系数 $c$,从而提高阻尼比 $\zeta$,降低共振峰高度。由频响函数对 $r$ 求极值可得:

$$|H|_{\max} = \frac{1}{2k\zeta\sqrt{1-\zeta^2}}$$

随着 $\zeta$ 增大,该极值单调下降。当 $\zeta \geq 1/\sqrt{2} \approx 0.707$ 时,频响曲线不再存在峰值,系统呈现单调下降的低通特性。工程实现上,典型方案包括约束阻尼层(constrained layer damping)、粘弹性阻尼贴片、橡胶减振垫,以及在精密设备中常用的油液阻尼器。代价是阻尼会持续消耗能量,在频带其他位置的响应也会被压低(高频隔振性能下降),并且粘弹性材料通常带来附加质量与温度依赖性。

### 2)失谐(改 k 或 m)

第二种思路是直接把 $\omega_0 = \sqrt{k/m}$ 推出激励频段,使系统始终远离共振区工作。工程上的经验准则是要求激励频率 $\omega_f$ 与固有频率 $\omega_0$ 的相对偏差大于约 20%,即 $|\omega_f - \omega_0|/\omega_0 > 0.2$,以此保证频响函数远离峰值区。实现方法包括调整结构刚度(改变截面尺寸、增加加强筋)或调整质量分布(局部减重或配重)。

一个典型例子是多旋翼无人机机架设计:桨叶通过频率 $\text{BPF} = N_{\text{blade}} \cdot \text{RPM}/60$ 是机架最主要的激励源,因此机架的一阶弯曲与扭转模态需要明确地与 BPF 拉开距离。在中小型四旋翼上,这通常意味着把机架基频拉到 200 Hz 以上,或者反过来把易共振模态压到 50 Hz 以下,留出充足的安全裕度。这种方法的局限在于,当激励频率本身随工况变化(变转速、变载荷)时,固定的失谐设计无法全程有效。

### 3)动力吸振器 TMD(加一个二阶子系统)

调谐质量阻尼器(Tuned Mass Damper, TMD)是在主系统上挂载一个由附加质量 $m_a$、刚度 $k_a$、阻尼 $c_a$ 构成的次级二阶系统,通过反共振机制将原系统在共振频率附近的单一高峰拆分为两个较低的次峰。Den Hartog 在经典工作中给出了无阻尼主结构条件下的最优参数:定义质量比 $\mu = m_a/m$,则最优频率比与最优阻尼比为

$$\frac{\omega_{a,\text{opt}}}{\omega_0} = \frac{1}{1+\mu}, \qquad \zeta_{a,\text{opt}} = \sqrt{\frac{3\mu}{8(1+\mu)^3}}$$

按此参数调谐后,主结构在原共振频率附近的响应被显著压低,但代价是带宽外出现两个对称的小峰。TMD 的最著名应用是台北 101 大楼顶部的约 660 t 球形阻尼器,用于抑制风载下的低频摆动。在机械工程中,曲轴扭振减振器、高压输电线的 Stockbridge 阻尼器、桥梁的人致振动控制也都属于这一范畴。TMD 的优点是无源、可靠,缺点是附加质量、占用空间,且对调谐误差较为敏感——当主结构频率因温度、载荷或老化漂移时,吸振效果会迅速下降。

### 4)隔振(低频隔振器)

与前几种方法不同,隔振并不试图压低共振本身,而是在激励源与被保护对象之间插入一个低频弹性环节,使激励无法以原始强度传入。定义传递率为基础位移到被保护对象位移的频响函数模:

$$T(r) = \sqrt{\frac{1 + (2\zeta r)^2}{(1-r^2)^2 + (2\zeta r)^2}}$$

可以证明,只有当 $r = \omega_f/\omega_n > \sqrt{2}$ 时 $T < 1$,即必须使隔振器的固有频率 $\omega_n$ 显著低于待隔离的激励频率 $\omega_f$,才能获得隔振效果。在该高频段,阻尼反而会让传递率变差,因此典型设计中隔振器的阻尼比取得较小(0.05~0.15 量级)以兼顾共振区的临时通过。

工程实例包括:IMU 减振座(把电机激励隔离在数百 Hz 以上,避免污染陀螺测量)、相机云台减振、精密光学平台的空气弹簧基座、半导体光刻机的主动-被动复合隔振系统。隔振方法的核心权衡是低频与稳定性之间的矛盾:隔振器越软,$\omega_n$ 越低,高频隔振性能越好,但静态变形与低频晃动也越显著。

## 四、主动反馈类

被动方法的根本限制在于:一旦结构参数固定,频响曲线就被固定下来,无法响应工况变化。主动方法通过引入传感器、执行器与控制器,把系统的等效阻尼或刚度变成可调参数,从而获得更强的适应性,但代价是需要供电、引入了潜在的稳定性问题。

### 5)主动阻尼(反馈到执行器)

最朴素的主动抑振是速度反馈:测量系统的速度 $\dot{x}$,通过执行器施加反向力 $F = -G\dot{x}$,系统方程变为

$$m\ddot{x} + (c+G)\dot{x} + kx = F_{\text{ext}}$$

等效阻尼系数从 $c$ 提升为 $c+G$,等效阻尼比为 $\zeta' = (c+G)/(2\sqrt{mk})$。这相当于"凭空"增加了阻尼,不需要附加阻尼材料或附加质量,且反馈增益 $G$ 可以根据工况调节。

典型应用包括汽车主动悬挂、磁悬浮转子的主动平衡、大型柔性结构(空间桁架、薄板)的主动振动控制,以及精密设备中的主动隔振平台。主动阻尼的代价不仅在硬件成本(传感器、执行器、电源、控制器),更在于稳定性:由于执行器存在动力学延迟、传感器存在噪声、控制律存在离散化误差,过高的反馈增益可能在频带外引发新的不稳定模态。实际设计中通常需要配合带通滤波,只在共振频段实施反馈,这就引出了下一类方法——信号层面的处理。

## 五、信号/输入端处理

前述方法都试图改变物理系统本身的动力学。第六、第七种方法则反其道而行:不去改物理系统,而是在测量信号端或指令信号端做手脚,使共振要么"看不见",要么"不被激发"。这在数字控制系统中实现成本很低,因此在嵌入式机器人、3D 打印、数控机床等领域应用极为广泛。

### 6)陷波滤波(notch,改测量)

陷波滤波器的目标是在保留其他频率成分的前提下,在测量信号中精准削去某一频率分量。典型的二阶陷波器传递函数为

$$H_n(s) = \frac{s^2 + \omega_n^2}{s^2 + (\omega_n/Q_n)s + \omega_n^2}$$

其中 $\omega_n$ 为陷波中心频率,$Q_n$ 控制陷波宽度。将 $\omega_n$ 对准激励基频及其重要倍频,可以在频域选择性地"挖掉"对应分量。

最典型的例子是 PX4、ArduPilot 等开源飞控在 gyro 信号链路上配置的多组陷波器(包括静态 notch 与基于 FFT 估计的动态 notch),用于压制电机不平衡与桨叶通过频率引起的伪角速度信号,避免这些高频分量进入姿态控制环并被微分器放大成噪声力矩。机床伺服系统中也常用陷波器来去除丝杠扭振或皮带固有频率对位置环的污染。

陷波法的本质局限必须明确:它并不抑制物理振动本身,只是从控制器"看到"的信号中移除了对应频率,从而避免控制器对其作出有害响应。物理上,机架仍在振动,机构仍在受力。当物理振幅本身已经威胁结构安全时,陷波法无能为力,必须配合机械手段。

### 7)输入整形(input shaping,改指令)

输入整形是在指令端而非反馈端的处理方法。其核心思想是:如果一个阶跃指令会激发系统在固有频率处的瞬态振动,那么可以把这个阶跃拆分为若干个时间错开、幅值精心选择的小阶跃,使每一个小阶跃单独激发的瞬态在叠加后相互抵消。

最简单的零振动(Zero Vibration, ZV)整形器使用两个脉冲,其参数可由欠阻尼二阶系统的瞬态响应推导得到。定义衰减因子

$$K = \exp\left(-\frac{\zeta\pi}{\sqrt{1-\zeta^2}}\right)$$

则两个脉冲的幅值与时间为

$$A_1 = \frac{1}{1+K}, \quad A_2 = \frac{K}{1+K}, \quad t_1 = 0, \quad t_2 = \frac{\pi}{\omega_0\sqrt{1-\zeta^2}}$$

在理想线性系统中,第二脉冲发出后系统的残余振动严格为零。后续发展出 ZVD(零振动加导数)、EI(extra-insensitive)等变种,以提升对频率估计误差的鲁棒性,代价是更长的指令延迟。

输入整形在 Klipper、Marlin 等 3D 打印固件中已成为标准功能(用户通过加速度计标定打印机的固有频率与阻尼,固件自动生成整形参数),也广泛用于塔吊吊载防摆控制、晶圆搬运机器人的快速定位、硬盘磁头的寻道控制。其本质代价是引入了大约半个共振周期的指令延迟——这对带宽要求高的伺服系统是不可忽视的损失,但对加减速类离散任务通常完全可以接受。

## 六、对比与小结

回顾全部七种方法可以发现,它们都是对同一个二阶受迫振动方程在不同位置的"动手":有的改物理参数,有的加附加结构,有的引入反馈力,有的在信号链路上做处理,有的在指令端做预补偿。下表从干预对象与能量需求两个维度做横向对比:

| 方法 | 干预对象 | 是否需外加能量 |
|------|---------|---------------|
| 增大阻尼 | 阻尼系数 c | 否(被动) |
| 失谐 | 刚度 k 或质量 m | 否(被动) |
| TMD | 附加二阶子系统 | 否(被动) |
| 隔振 | 支撑刚度 | 否(被动) |
| 主动阻尼 | 反馈力 | 是(需供电与控制器) |
| 陷波滤波 | 测量信号 | 是(数字计算) |
| 输入整形 | 指令信号 | 否(开环数字处理) |

从这张表可以提炼出工程选型的基本原则。如果共振源明确、激励频段固定、且对附加质量与体积不敏感,被动方法(增阻尼、失谐、TMD、隔振)往往是首选,因为它们可靠、无源、无失稳风险。如果激励频率随工况大范围变化,或对附加质量极为敏感(如航天结构、高速旋转机械),主动阻尼是合适的方向,但需仔细处理稳定性问题。如果共振并不直接威胁结构,而是污染控制系统或测量结果,陷波滤波几乎是性价比最高的选择。如果系统主要承担离散运动任务(打印、搬运、定位),且对路径精度要求高于带宽,输入整形能以零硬件成本带来显著的振动抑制效果。

最后值得强调的是,实际工程中很少只用单一方法,更常见的是组合使用:例如无人机通常同时采用机架失谐、IMU 减振座与 PX4 的陷波滤波三重防线;3D 打印机则在机械结构刚化的基础上叠加 input shaping;台北 101 在结构自身阻尼之上还要靠 TMD 控制人感舒适度。理解每种方法的干预节点与代价,才能在面对具体问题时迅速判断该在哪一层做工。
