**记几何光学最有效的方法：先记光线怎么走，再用图把公式找回来。** 可以把知识串成一条线：

**界面决定反射、折射 → 曲面让光会聚、发散 → 光线交点决定成像。**

先按中学到大学基础几何光学的范围讲。

**1．反射：记“关于法线对称”**

法线就是垂直于镜面的线。入射角 (i)、反射角 (r) 都从法线量起，因此：

\[
\boxed{i=r}
\]

口诀：**角从法线量，来去两边同。**

镜面反射和漫反射都遵守这个公式。漫反射的表面凹凸不平，各处法线方向不同，所以反射光散向各处。

平面镜成像直接记“镜面对称”：

- 像和物到镜面的距离相等。
- 像与物等大，像是正立的虚像。

“虚像”的意思是：**光线的反向延长线相交，实际光线没有在那里会合。**

**2．折射：记“折射率大，角度小”**

光从一种介质进入另一种介质，方向由折射定律决定：

\[
\boxed{n_1\sin\theta_1=n_2\sin\theta_2}
\]

这里 (n_1,n_2) 是两侧介质的折射率，(\theta_1,\theta_2) 都是光线与法线的夹角。

公式两边相等，所以：

> **哪边折射率大，哪边与法线的夹角就小。**

例如空气进入水，水的折射率更大，光就**靠近法线**；水进入空气，光就**远离法线**。

折射率还可以用速度记：

\[
\boxed{n=\frac{c}{v}}
\]

其中 (c) 是真空光速，(v) 是光在介质中的速度。于是可以连着记：

**折射率大 → 光速小 → 光线更靠法线。**

全反射也从同一公式得到：光必须从**高折射率进入低折射率**。当折射角达到 (90^\circ) 时，入射角就是临界角 (C)：

\[
\boxed{\sin C=\frac{n_{\text{低}}}{n_{\text{高}}}}
\]

入射角大于 (C)，就发生全反射。记作：**高到低，大于临界。**

**3．镜子和透镜：记“凹镜、凸透镜会聚”**

先把这四种器件配对：

| 器件   | 对平行于主轴的光的作用 |
| ------ | ---------------------- |
| 凹面镜 | 会聚                   |
| 凸面镜 | 发散                   |
| 凸透镜 | 会聚                   |
| 凹透镜 | 发散                   |

透镜这一表格默认是**普通玻璃透镜放在空气中**。**

**4．成像：一条公式，配一套符号**

薄透镜和近轴条件下的球面镜，都可以使用：

\[
\boxed{\frac1f=\frac1u +\frac1v=1/物距+1/像距
}\]

这里 (f) 是焦距，(u) 是物距，(v) 是像距。采用下面这套符号约定：

| 量       | 正号     | 负号     |
| -------- | -------- | -------- |
| 焦距 (f) | 会聚器件 | 发散器件 |
| 物距 (u) | 实物     | 虚物     |
| 像距 (v) | 实像     | 虚像     |

放大率为：

\[
\boxed{m=\frac{h'}h=-像距/物距}
\]

其中 (h,h') 分别是物和像的有符号高度。因此：

- (m>0)：正立；(m<0)：倒立。
- (|m|>1)：放大；(|m|<1)：缩小。

**课本可能采用另一套正负号约定，做题时要整套使用课本的约定。**

球面镜还多一个关系：

\[
\boxed{f=\frac R2}
\]

即近轴条件下，**焦距是曲率半径的一半**；若使用有符号量，(R) 的符号也要与约定一致。

**5．凸透镜成像表：只抓住 (f) 和 (2f)**

对于实物，凸透镜的成像规律是：

| 物的位置 | 像的位置                   | 像的性质         |
| -------- | -------------------------- | ---------------- |
| (u>2f)   | (f<v<2f)                   | 倒立、缩小、实像 |
| (u=2f)   | (v=2f)                     | 倒立、等大、实像 |
| (f<u<2f) | (v>2f)                     | 倒立、放大、实像 |
| (u=f)    | 出射光平行，无有限位置的像 | —                |
| (0<u<f)  | 物体同侧                   | 正立、放大、虚像 |

这张表可以用公式现场恢复。例如物体放在 (2f) 处：

\[
\frac1v=\frac1f-\frac1{2f}=\frac1{2f},
\]

所以像也在 (2f) 处，放大率为 (-1)，就是倒立等大。

记三个关键点就够了：

**焦点处分界，二倍处等大；焦外成倒立实像，焦内成正立放大虚像。**

对于实物，凹透镜和凸面镜都成**正立、缩小的虚像**。

**6．真正帮助记忆的是画三条特殊光线**

凸透镜最常用的三条光线：

2. 平行主轴入射 → 折射后经过另一侧焦点。
4. 经过入射侧焦点 → 折射后平行主轴。
6. 经过光心 → 在薄透镜近似下方向不变。

凹面镜也有对应的三条：

2. 平行主轴入射 → 反射后经过焦点。
4. 经过焦点 → 反射后平行主轴。
6. 沿经过曲率中心的方向入射 → 原路反射。

**每题先画其中两条：实际光线相交就是实像，反向延长线相交就是虚像。** 这样像在哪里、正立还是倒立，都会从图上出现。

每天用几分钟合上书，完成这三个动作：**画法线，写折射定律；画凸透镜两条光线；用成像公式算一次 (u=2f)。** 公式、图像和成像规律就会连在一起。
