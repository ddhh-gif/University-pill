LC Oscillator Circuits

An Impedance Method (Phasor) Analysis of LC / RLC Oscillators

电路分析 · 电工 · 课程笔记

I. Introduction

LC 振荡电路以电感 $L$ 与电容 $C$ 构成的谐振回路为核心。理想无耗时，能量在电感的磁场与电容的电场之间周期交换，形成等幅振荡；实际电路中的电阻 $R$ 引入损耗，使振荡逐渐衰减。

按 $R$、$L$、$C$ 的连接方式，可分为串联 RLC 与并联 RLC 两类基本振荡回路。相量法（阻抗法）把时域微分方程化为复数代数方程，可直接得到每个元件电压、电流的幅值与相位。

本页重点标注每个器件两端的电位：任意两端元件的电压，都等于其两端节点电位之差。

II. The Impedance Method

对同一角频率 $\omega$ 的正弦量，相量法用复数表示振幅与相位；时域中的微分变为乘以 $j\omega$，积分变为除以 $j\omega$。于是欧姆定律在复数域中仍然成立：$U = IZ$。

三种基本元件的阻抗见表 I：电阻 $Z_R = R$，电感 $Z_L = j\omega L$，电容 $Z_C = 1/(j\omega C)$。

TABLE I — 基本元件的阻抗
元件阻抗 $Z$电压与电流
电阻 R$R$同相
电感 L$j\omega L$电压超前 $90^\circ$
电容 C$1/(j\omega C)$电压滞后 $90^\circ$

元件串联时阻抗相加，得到串联 RLC 的总阻抗：

$$Z = R + j(\omega L - \frac{1}{\omega C}) \tag{1}$$

并联时用导纳 $Y = 1/Z$ 相加更为方便。

III. Series Resonance

串联 RLC 的谐振角频率为

$$\omega_0 = \frac{1}{\sqrt{LC}} \tag{2}$$

谐振时 $\omega_0 L = 1/(\omega_0 C)$，感抗与容抗大小相等、符号相反而相互抵消，串联阻抗达到最小值 $Z(\omega_0) = R$，电路呈纯阻性，电流达到最大。

此时电感电压与电容电压幅值相等、相位相反，即 $U_L = -U_C$；电阻电压 $U_R = IR = U_s$。定义品质因数 $Q = \omega_0 L / R$，则高 $Q$ 时

$$U_L = U_C = Q \cdot U_s \tag{3}$$

即 $L$、$C$ 两端电压可远高于电源电压——这就是串联谐振的电压放大（电压谐振）。

每个器件两端的电位：任意两端元件的电压等于其两端节点电位之差。图 1 中，电源两端为 0 V 与 $U_s$；R 两端为 $V_A$ 与 $V_B$；L 两端为 $V_B$ 与 $V_C$；C 两端为 $V_C$ 与 0 V。谐振时 $U_L = -U_C$，L、C 两端电压相互抵消，电源电压全部落在电阻上。

算例（图 1）：取 $R = 100$ Ω，$L = 0.3$ H，$C = 40$ μF，$\omega = 500$ rad/s，$U_s = 100∠30°$ V。则 $X_L = \omega L = 150$ Ω，$X_C = 1/(\omega C) = 50$ Ω，$Z = 100 + j100 = 141.4∠45°$ Ω，电流 $I = U_s / Z = 0.707∠−15°$ A；各元件电压为 $U_R = 70.7∠−15°$ V，$U_L = 106∠75°$ V，$U_C = 35.35∠−105°$ V。

IV. Parallel Resonance

并联 RLC 的导纳为

$$Y = \frac{1}{R_p} + j(\omega C - \frac{1}{\omega L}) \tag{4}$$

谐振时导纳虚部为零，$Y(\omega_0) = 1/R_p$，输入阻抗达到最大值 $Z_p(\omega_0) = R_p$，电路呈纯阻性且端电压最大。两支路电流 $I_L$ 与 $I_C$ 幅值相等、相位相反，在 L–C 回路内部形成环流；电源只提供电阻支路电流 $I_R = U/R_p$。

并联品质因数为 $Q_p = \omega_0 R_p C = R_p/(\omega_0 L)$。高 $Q$ 时支路环流远大于电源电流，称为电流谐振。

V. Oscillator Circuits

各种 LC 振荡电路都以谐振回路为基础：

  • 串联 RLC 振荡器：利用谐振时 $L$、$C$ 两端的高电压作为正反馈信号。
  • 并联 RLC 谐振槽（tank）：谐振时阻抗最大、内部环流最大，用作选频与储能网络。
  • 反馈型振荡器（Colpitts、Hartley、Armstrong）：由放大器与 LC 网络构成正反馈回路，振荡频率由 LC 网络决定：
$$f_0 = \frac{1}{2\pi\sqrt{LC}} \tag{5}$$

其中 Colpitts 电路用电容分压，等效电容 $C_{\mathrm{eq}} = C_1 C_2 / (C_1 + C_2)$；Hartley 电路用电感抽头实现反馈。起振还需满足环路增益条件（幅值不小于 1、相移为 $2\pi n$）。

VI. Conclusion

相量法把 LC / RLC 振荡电路的微分方程化为复数代数运算：串联谐振表现为阻抗谷与电压放大 $U_L = U_C = Q U_s$，并联谐振表现为阻抗峰与电流放大 $I_L = I_C = Q_p I_R$。每个器件的两端电位都可由节点电位差直接读出，这是理解振荡回路电压分布的关键。
