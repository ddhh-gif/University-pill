## 〇、导论 / 总论

### 马克思主义的定义与构成

**【选择】** 狭义：马克思、恩格斯创立的**基本理论、基本观点、基本学说**体系。

- 最根本的世界观和方法论 = **辩证唯物主义和历史唯物主义**。
- 最崇高的社会理想 = **共产主义**。
- 基本特征 = 实践基础上**科学性和革命性的统一**（科学性、人民性、实践性、发展性）。
- 三大组成部分：**哲学（理论基础）、政治经济学（主要内容）、科学社会主义（核心/归宿）**。
- 三大直接理论来源：**德国古典哲学、英国古典政治经济学、英法空想社会主义**。
- 易错：科学社会主义≠空想社会主义；来源是"三大思潮"，不是"法国理性主义"。

### 马克思主义的诞生与科学化

**【选择】** 诞生标志 = **1848《共产党宣言》**；使社会主义从空想变科学 = **唯物史观 + 剩余价值学说**。

- 易错：不是"阶级斗争学说"、不是"进化论"。

### 空想社会主义

**【选择】** 三大代表 = **圣西门、傅立叶、欧文**。

- 易错：**康德不是**空想社会主义者。

### 共同理想

**【选择】** 当代中国人的共同理想 = **建设中国特色社会主义**（共产主义是远大理想）。

## 一、第一章·唯物论

### 哲学基本问题

**【选择】** 哲学基本问题 = **思维与存在（意识与物质）的关系**。

- 第一方面：何者为**第一性** → 划分唯物 / 唯心（本体论）。
- 第二方面：二者**有无同一性** → 划分可知论 / 不可知论。
- 易错：第一方面问的是"谁是第一性"，不是"有无统一性"。

### 物质范畴

**【选择】** 马克思主义物质的唯一特性 = **客观实在性**；物质 = 不依赖意识、又能被意识感知的**客观实在**。

- 三形态：古代朴素（具体物质形态）→ 近代形而上学/机械（原子）→ 辩证唯物主义（客观实在）。
- 易错：物质≠具体实物、≠原子、≠社会存在；"客观实在"是唯一特性。

### 物质与运动

**【选择】** 运动是物质的**根本/根源属性、存在方式**；**物质是运动的承担者**。

- "物质是一切变化的主体" → **运动是物质的运动**（不是思维的运动）。
- 易错：没有不运动的物质（反对形而上学）；运动是物质的属性（反对唯心主义）。

### 运动与静止

**【选择】** 运动**绝对、无条件、永恒**；静止**相对、有条件、暂时**；静止是运动的特殊状态。

- "水不流"（桥流水不流）→ 特定参照下的**相对静止/稳定性**。
- 只承认运动、否认静止 → **相对主义、诡辩论**；把静止绝对化 → **形而上学不变论**。
- 易错：动中有静、静中有动，不能割裂。

### 意识

**【选择】** 意识 = **客观存在的主观映像**（内容客观、形式主观）。

- 起源：自然界长期发展的产物 + **社会劳动**的决定作用。
- 本质：人脑的机能、对客观存在的反映。
- 能动性："心不使焉则白黑在前而目不见" → 意识具有**能动性**。
- 易错：错误意识**也是**对客观存在的反映（歪曲反映）；鬼神、外星人以人为原型 → 仍是客观反映。

### 意识是主观与客观的统一（辨析高频）

**【大题】**

- 内容客观：正确/错误意识都是对客观存在的反映。
- 形式主观：感性/理性形式的主观性、个体差异、创造性。
- 主客观统一：反映对象客观、差异根源客观、**任何歪曲虚假的创造也是客观对象的反映**。
- 结论：对。

### 物质第一性、意识第二性

**【大题】** ①辩证唯物主义立场；②物质定义（客观实在、唯一特性客观实在性）；③意识是自然界长期发展产物、依赖并决定于物质；④结论：物质第一性、意识第二性。

### 世界的物质统一性

**【大题】** ①世界本原是物质；②物质客观实在、不依赖意识；③自然、社会、思维都是物质的不同表现；④统一是**多样性的统一**；⑤意义：坚持唯物主义一元论，反对唯心主义和二元论。

- 关联金句："除了运动的物质，世界上什么也没有"：**物质—运动—世界物质统一性**链条作答（运动、物质统一性不能丢）。

### 人与自然 / 生态

**【选择】** 生态问题的**根本原因 = 资本主义制度**（生产方式与剥削关系）。

- 易错：不是"自然资源有限""人类中心论"本身。

### 人工智能（论述备选）

**【大题】** 一分为二：①工具，能延伸人的能力、提高效率；②不具人的意识/社会性，不能取代人；③作用受社会制度、利益关系制约；④结论：造福人类需正确引导。

## 二、第一章·辩证法

### 唯物辩证法的总特征

**【选择】** 总观点/总特征 = **联系和发展**。

### 联系

**【选择】** 联系的特点：**普遍性、客观性、多样性、条件性**。

- 条件性的方法论：**利用有利条件、化不利为有利**（不是"唯条件论"、不是"超越规律创造条件"）。
- "一棵树两种算法" → 联系的**多样性**。

### 发展

**【选择】** 发展的实质 = **新事物产生、旧事物灭亡**。

- 新事物≠时间先后：看**是否符合发展必然趋势、有无强大生命力**。
- 易错：出现晚的不一定是新事物。

### 唯物辩证法 vs 形而上学

**【选择】** 斗争焦点 = **是否承认矛盾是事物发展的动力**。

- 对立：联系 vs 孤立、发展 vs 静止、全面 vs 片面、承认矛盾 vs 否认矛盾。
- **【大题】** 辩证法：普遍联系、永恒发展、矛盾是动力；形而上学：孤立、静止、否认矛盾；关系：对立（否定与超越）。

### 矛盾（对立统一规律）

**【选择】** 对立统一规律是唯物辩证法的**实质与核心**，是事物发展的**根本规律**，揭示发展的**动力和源泉**。

- 同一性（统一）与斗争性（对立）辩证统一。
- 普遍性（共性）与特殊性（个性）：**共性寓于个性之中**。
- 主要矛盾/次要矛盾 → **重点论与两点论的统一**（抓主要、兼顾次要）。
- 易错：普遍性与特殊性是**共性与个性**，不是"整体与部分"。

**【大题·矛盾分析法（医患/中国式现代化）】** ①矛盾普遍性（时时有矛盾）；②矛盾特殊性（具体问题具体分析）；③抓主要矛盾/矛盾主要方面（重点论）；④两点论与重点论统一；⑤具体分析、对症下药。

### 量变质变

**【选择】** 适度原则、"善不积不足以成名" → **量变与质变**关系。
**【大题】** ①量变：数量增减、场所变更，渐进、连续；②质变：性质根本变化、飞跃、连续性的中断；③量变是质变的**必要准备**，质变是量变的**必然结果**；④相互渗透（总量变中有部分质变、质变中有量的扩张）；⑤方法论：重视量的积累、抓住时机促成质变、坚持适度原则。

### 否定之否定

**【选择】** 辩证否定的实质 = **事物的自我否定**；"扬弃" = **既克服又保留**。
**【大题·否定不是"一刀两断"】** ①辩证否定是自我否定；②包含**克服**（不合理因素）与**保留**（合理因素）；③是发展的环节、联系的环节；④否定之否定：三段两次否定、**前进性与曲折性统一**（螺旋式上升、波浪式前进）；⑤结论：错在把否定当成简单抛弃。

### 五对范畴（联系和发展的基本环节）

**【选择】** 五对：**内容与形式、本质与现象、原因与结果、必然与偶然、现实与可能**。

- **本质与现象**：
  **【大题】** ①本质：内在联系、根本性质；现象：外在表现；②本质决定现象、现象表现本质；③现象有真象/假象，**假象也是本质的表现**（歪曲表现）；④方法论：透过现象看本质。
  - 易错："假象不表现本质"是**错的**。
- **必然与偶然**：
  **【大题】** ①必然性：内部根本矛盾决定、一定发生、居支配地位、决定方向；偶然性：非根本矛盾/外部条件、可发生可不发生、居从属地位、起促进或延缓作用；②对立：原因、地位、作用、表现形式不同；③统一：必然寓于偶然之中、偶然体现并受制于必然、二者在一定条件下**相互转化**；④方法论：把握必然、重视机遇。
- **现实与可能**：
  **【选择】** 可能 = 事物内部潜在的、预示发展前途的**种种趋势**（区分可能与不可能、现实可能与非现实可能）。
  - 易错：可能性≠现实性，也≠单一趋势。

### 中庸之道的哲学内涵

**【大题】** ①把握对立差别、保持对立面和谐统一（矛盾同一性），反对无原则和稀泥；②做事适中适度、无过无不及；③防止"过"与"不及"，保持质与量统一的**适度**思想；④具体问题具体分析（矛盾特殊性）；⑤原则性与灵活性结合（孟子发展）；⑥非折衷主义、非墨守成规。

### 中国式现代化（辩证法应用）

**【大题】** ①矛盾普遍性与特殊性：既遵循现代化一般规律（普遍），又有中国特色（特殊）；②质量互变：渐进积累→质的飞跃；③否定之否定：对传统模式的辩证否定、自我超越，波浪式前进、螺旋式上升。

## 三、第二章·认识论

### 实践

**【选择】** 实践 = 人**能动地改造世界**的客观物质性活动。

- 基本形式：**物质生产、社会政治、科学实验**（艺术创作**不属于**基本形式）。
- 基本特征：**客观物质性、自觉能动性、社会历史性**。
- 实践的**决定作用**（认识的基础）：**来源、动力、标准、目的**。
  - "技术需要比十所大学更能推动科学" → 实践是**认识发展的动力**。
  - "没有调查没有发言权""不登高山不知天之高" → 实践是**认识的来源**。
- **【大题·实践观点是首要基本观点】** 实践是认识的起点和归宿，决定认识的产生、发展、检验；体现认识论唯物主义。

### 认识的本质与两条路线

**【选择】** 认识的本质 = **实践基础上主体对客体的能动反映**（革命的能动的反映论）。

- 两条路线：唯物主义反映论 vs 唯心主义先验论；**能动反映论 vs 直观反映论**。
- "一切知识来自对客观世界的感觉" → 唯物主义反映论。
- "认识是主体对客体的反映" → **一切唯物主义都承认**（不只有辩证唯物主义）。
- "鬼神是否有人见闻" → **直观反映论**（忽视能动性）。

### 感性认识与理性认识

**【选择】** 感性：**感觉、知觉、表象**（初级阶段，反映现象）；理性：**概念、判断、推理**（高级阶段，反映本质）。

- 关系：理性依赖感性、感性有待上升为理性、二者**相互渗透**。
- 易错：**理性认识不比感性认识更真实可靠**（只是阶段不同）。

### 认识运动规律

**【大题】** ①实践→认识→再实践→再认识，**无限反复、无限发展**；②两次飞跃：感性→理性（第一次）、理性→实践（第二次，更重要）；③去粗取精、去伪存真、由此及彼、由表及里。

### 真理

**【选择】** 真理 = 对客观事物及其规律的**正确认识**。

- **客观性**：内容客观、检验标准（实践）客观；真理**一元**。
- **真理没有阶级性**（有阶级性的是对真理的解释和运用）。
- **绝对性**：正确性的无条件性、无限趋势；**相对性**：广度深度有限、近似性。
  - 只讲相对不讲绝对 → **相对主义**。
- 真理是**绝对性与相对性的统一**：绝对寓于相对之中、相对包含绝对因素、无数相对真理之和构成绝对真理；是**过程**。
- 三角形内角和随条件变 → **真理都是在一定条件下成立**。
- 易错：真理≠客观事物本身；真理有主观形式但内容客观。

**【大题·真理的客观性及绝对性相对性】** ①客观性：内容客观+标准客观→真理一元；②绝对性=正确性无条件性；③相对性=有限性；④关系：绝对寓于相对、相对含绝对、相对→绝对的转化过程；⑤意义：正确对待马克思主义（坚持+发展）。

**【大题·真理问题的唯物论与辩证法】** 唯物论→客观性（内容客观、标准客观、一元）；辩证法→绝对性与相对性统一、具体性条件性、是过程。

### 实践是检验真理的唯一标准

**【大题】** ①真理本性是主客观相符合；②实践是**主观见之于客观**的活动、具有**直接现实性**，能把观念变为现实；③把理论与结果对照，符合即真理；④逻辑证明是辅助，不能替代实践。

### 真理与价值

**【选择】** 价值特性：**主体性、客观性、多维性、社会历史性**；价值评价以主客体价值关系为对象、结果与主体相关。

- 真理尺度（合规律）与价值尺度（合目的）**辩证统一**：价值尺度以真理为前提，真理尺度以价值为动力。

### 必然与自由

**【大题】** ①必然=受客观规律支配、盲目被动；自由=认识规律并据以改造世界（意志自由+行动自由）；②对立：自由受必然制约、无绝对自由（**必然是自由的限度**）；③统一：自由以认识必然、尊重规律为基础（**必然是自由的根据**）；④"从心所欲不逾矩"= 自由与必然统一。

### 认识世界与改造世界 / 群众路线

**【大题·认识论与群众路线】** ①实践是认识基础↔群众路线以实践为基础；②"从群众中来、到群众中去"↔实践—认识—再实践；③认识与实践的统一↔政策从群众来、回群众中去检验；④两次飞跃↔群众经验上升为政策再回到实践。

## 四、第三章·唯物史观

### 社会历史观基本问题

**【选择】** 基本问题 = **社会存在与社会意识的关系**；唯物史观回答：**社会存在决定社会意识**。

- 第一次科学回答"谁是历史创造者"、宣告唯心史观破产 = **马克思主义唯物史观/历史观**。

### 社会存在

**【选择】** 社会存在 = **地理环境 + 人口因素 + 物质生产方式**。

- 易错：**政治体制属于上层建筑，不属于社会存在**；地理环境属于社会存在但**不是决定力量**。
- 人口：数量、质量、结构对发展起**加速或延缓**作用（不是决定力量）。

### 社会意识

**【选择】** 社会意识相对独立性（5 表现）：①与社会存在发展**不完全同步**（超前/滞后）；②与经济发展水平**不平衡**；③**历史继承性**；④各形式**相互影响**；⑤对社会存在**能动反作用**（先进促进、落后阻碍）。

- "经济落后国家哲学仍能演奏第一提琴" → 社会意识相对独立性/不平衡性（**正确**）。

### 生产力

**【选择】** 生产力 = 改造自然、获取物质资料的能力；**最终决定力量**。

- 要素：劳动者（最活跃）、劳动资料（生产工具是标志）、劳动对象 + **科学技术（第一生产力/智能要素）**。
- 特性：物质性、社会性、历史性。
- **【大题·科学技术是第一生产力】** 科技渗透到劳动者、劳动资料、劳动对象中转化为直接生产力；提高劳动者技能、改进工具、拓展对象；是先进生产力的集中体现和主要标志。

### 生产关系

**【选择】** 生产关系 = 生产中形成的不以人意志为转移的经济关系；**生产资料所有制是基础**。

### 生产力与生产关系 / 社会基本矛盾

**【选择】** 两对社会基本矛盾：**生产力—生产关系**、**经济基础—上层建筑**；其中**生产力与生产关系的矛盾更基本**。

- 规律：**生产关系一定要适合生产力状况**。
  **【大题·生产力与生产关系辩证关系】** ①生产力决定生产关系（性质、变革）；②生产关系反作用于生产力（适合促进、不适合阻碍）；③构成矛盾运动，体现"一定要适合"规律；④是我国经济体制改革的理论依据。

**【大题·为什么两对矛盾是社会基本矛盾】** ①囊括生产力、生产关系（经济基础）、上层建筑三大领域，构成社会基本结构；②贯穿每个社会形态始终；③规定社会形态/制度的基本性质；④是其他一切社会矛盾的根源；⑤体现"两个一定要适合"规律，是社会发展的基本动力。

### 经济基础与上层建筑

**【选择】** 经济基础 = 占统治地位的生产关系总和；上层建筑 = 意识形态 + 相应制度组织设施；**上层建筑的核心 = 国家政权**。

### 生产方式

**【大题·生产方式对社会发展的作用】** ①生产方式=生产力+生产关系的统一；②是社会存在和发展的基础、前提；③决定社会的结构、性质和面貌；④其变化决定社会形态更替。易错：决定力量是**生产方式/生产力**，不是地理环境。

### 社会形态 / 历史选择

**【选择】** 社会形态更替具有**统一性与多样性**、**历史选择性**（人们的历史选择归根结底是人民群众的选择）。

### 人的本质

**【选择】** 人的本质"在其现实性上是一切**社会关系的总和**"；**劳动**是人与动物区别的决定性因素。

- 易错：不是"自然属性总和"、不是"共同属性总和"。

### 人民群众与杰出人物

**【选择】** 人民群众是历史创造者（**群众史观** vs 英雄史观）。

- 群众—阶级—政党—领袖：阶级通常由政党领导、政党由领袖主持，四者构成有机整体。
  **【大题·杰出人物产生】** ①是历史**必然性与偶然性的统一**；②"时势造英雄"= 必然性（主导）；③具体是谁、何种才能 = 偶然性；④必然通过偶然开辟道路；⑤结论：不只凭个人才智（题目说法错误）。

### 改革 / 阶级斗争 / 革命

**【选择】** 改革 = 对社会制度的**改善和革新**（社会主义制度**自我完善和发展**），是社会主义发展的重要动力。

- 根本动力 = 社会基本矛盾；直接动力（阶级社会）= 阶级斗争；重要动力 = 革命、改革、科技、文化。
- 易错：改革不是"社会制度根本更替"（那是革命），也不是"向资本主义趋同"。

### 我国基本经济制度（唯物史观应用）

**【大题】** ①生产力决定生产关系；②我国处于社会主义初级阶段，生产力多层次、不平衡、先进生产力占主导；③必然要求**公有制为主体、多种所有制共同发展**；④符合"三个有利于"；⑤是社会主义性质与初级阶段国情决定，具有客观必然性。

## 五、第四、五章·政治经济学

### 自然经济与商品经济

**【选择】** 自然经济 = **自给自足**；商品经济 = **以交换为目的**的生产（本质是交换）。

### 商品经济产生条件

**【选择】** 两个条件：①**社会分工**；②**生产资料和劳动产品属于不同所有者**。

### 商品二因素

**【选择】** 使用价值：满足需要的有用性、**反映人与自然**、**自然属性**（一切劳动产品共有）；价值：凝结的无差别一般人类劳动、**反映人与人**、**社会属性**（商品特有）。

- 关系：对立统一（不可兼得 / 商品必须二者兼具；使用价值是价值的物质承担者）。
- 易错：**使用价值反映人与自然，价值反映人与人**（习题集此处答案有误，见附录）。

### 劳动二重性

**【选择】** **具体劳动**创造**使用价值**（自然属性）；**抽象劳动**创造**价值**（社会属性）；劳动二重性**决定**商品二因素。

- 是"理解政治经济学的枢纽"。
- 易错：二者是**同一劳动的两个方面**，不是两种独立劳动。

### 商品价值量

**【选择】** 由**社会必要劳动时间**决定（不是个别劳动时间、不是供求）；与劳动生产率**成反比**。

- 易错："价值量由供求关系决定"是**错的**；供求只影响**价格**。

### 货币

**【选择】** 本质 = **固定充当一般等价物的商品**；五职能：**价值尺度、流通手段、贮藏手段、支付手段、世界货币**。

### 价值规律

**【大题】** ①内容：价值量由社会必要劳动时间决定，按**等价交换**；②表现形式：**价格受供求影响、围绕价值上下波动**；③作用：自发调节资源配置、刺激生产力发展、导致优胜劣汰/两极分化。
**【选择】** 价值、价格、供求：价格由价值决定、受供求影响、围绕价值波动（价格既反映价值也反映供求）。

### 私有制商品经济基本矛盾

**【选择】** **私人劳动与社会劳动的矛盾**（通过交换解决）。

### 劳动力成为商品

**【选择】** 两条件：①劳动者是**自由人**；②**一无所有**（无生产资料）。

- 劳动力商品**最根本特点**：**使用价值是价值的源泉**（能创造大于自身价值的价值）。
- 是**货币转化为资本的决定性条件**。

### 资本主义生产过程

**【选择】** 资本主义生产过程 = **劳动过程与价值增殖过程的统一**。

- 剩余价值 = 雇佣工人创造的、被资本家无偿占有的、超过劳动力价值的部分。
- 不变资本 c（生产资料，只转移价值）／可变资本 v（劳动力，能增殖）；**剩余价值率 m′=m/v 反映剥削程度**。

### 剩余价值的生产方法

**【大题·两种基本方法】** ①绝对剩余价值：必要劳动时间不变，**延长工作日/提高强度**；②相对剩余价值：工作日不变，**提高全社会劳动生产率、缩短必要劳动时间**；③超额剩余价值：个别企业提高生产率、个别价值低于社会价值（是相对剩余价值的原因）；④都体现剥削关系。

### 资本积累与有机构成

**【选择】** 资本积累 = 用无偿占有的剩余价值扩大资本规模；资本有机构成 = **c:v**（由技术构成决定并反映其变化）。

### 资本主义基本矛盾与经济危机

**【大题·基本矛盾及必然趋势】** ①基本矛盾 = **生产社会化与生产资料资本主义私人占有**的矛盾；②表现：生产无限扩大 vs 有支付能力需求相对缩小、个别企业有组织 vs 社会生产无政府；③尖锐化不可避免；④趋势：资本主义必然灭亡、社会主义必然胜利。
**【选择】** 经济危机实质 = **生产相对过剩**（相对于有支付能力的需求），不是绝对过剩。

- 根源 = 资本主义基本矛盾；周期：危机—萧条—复苏—高涨。

### 垄断

**【选择】** 自由竞争→垄断的最根本标志 = **垄断在经济生活中占统治地位**。

- 垄断不能消除竞争（未消除竞争条件、需靠竞争维持、生产复杂多样）。
- 垄断利润 = 超过平均利润的高额利润，归根到底来自**剩余价值**。
- 垄断价格 = 成本价格 + 平均利润 + 垄断利润（未否定价值规律）。

### 国家垄断资本主义

**【选择】** 形成原因：生产力发展要求生产资料更大范围支配、经济波动/危机深化、缓和社会矛盾、协调利益关系。

- 实质：私人垄断资本利用国家机器为自己服务；**未改变垄断资本主义性质**。

### 经济全球化

**【选择】** 本质 = **资源配置的全球化**；表现 = 生产全球化、贸易全球化、金融全球化（+企业生产经营全球化）。

- 动因：科技进步与生产力发展、跨国公司、各国经济体制变革与国际经济组织。
- 影响：积极（技术/管理、就业、贸易、跨国公司）+ 消极（地位收益不平等、资源环境、经济风险）。

### 资本主义意识形态 / 新变化 / 金融危机

**【选择】** 资本主义意识形态 = 资产阶级**阶级意识**的集中体现。

- 当代资本主义新变化：在**制度基本框架内**变化，**根本性质未变**（私有制、雇佣劳动、剩余价值规律仍在）。
- 2008 金融危机影响：经济失调、政治体制失灵、社会流动性退化、社会极端思想抬头 → 需建国际经济新秩序、加强全球治理。

## 六、科学社会主义

### 社会主义从空想到科学

**【选择】** 理论基础 = **唯物史观 + 剩余价值学说**。

- 三大空想代表：圣西门、傅立叶、欧文。

### 社会主义发展道路

**【大题·多样性】** ①各国国情（经济、政治、文化、生产力）不同；②历史文化传统差异；③时代和实践不断发展；④必须把马克思主义基本原理与本国实际结合、走自己的路。

### 社会主义代替资本主义

**【大题·长期性曲折性】** ①任何社会形态都有相对稳定性；②资本主义各国经济政治发展不平衡；③资本主义生产关系对生产力还有容纳空间/自我调节能力；④社会主义实践需在各国具体条件下探索，会有曲折；⑤趋势必然、过程长期。

### "两个必然"与"两个决不会"

**【大题】** ①两个必然：资本主义必然灭亡、社会主义必然胜利；②两个决不会：旧制度在全部生产力发挥完之前不会灭亡、新制度在物质条件成熟前不会出现；③关系：必然性 + 长期性/条件性；④意义：坚定信念又尊重规律，立足国情。

### 无产阶级革命

**【答题·"同时发生"判断】** 马恩在**自由竞争资本主义**条件下曾认为革命将在**几个主要资本主义国家同时发生**（共同胜利论）；列宁在垄断阶段提出**一国或数国首先胜利**。→ 题目原句（同时发生）**正确**（习题集判错，见附录）。

### 共产主义

**【选择】** 分配原则 = **各尽所能、按需分配**；目标是**人的自由而全面发展**。

- **【大题·人的自由全面发展】** ①劳动成为自由自觉的活动；②摆脱旧式分工和私有制束缚；③人的能力、社会关系、个性全面发展；④以生产力高度发达和公有制为前提；⑤是共产主义的价值目标。

### 科学社会主义一般原则

**【大题】** ①以唯物史观和资本主义基本矛盾为"两个必然"依据；②无产阶级是最先进革命阶级；③无产阶级革命/专政；④公有制基础上组织生产、按劳分配；⑤有计划调节生产；⑥人与自然和谐；⑦科学理论指导；⑧无产阶级政党领导；⑨解放发展生产力、共同富裕。

- 正确把握：坚持原则 + 与本国实际结合 + 随实践丰富发展。

## 附录：习题集答案纠错 / 存疑清单

> 这些是"不能直接用题目答案"的地方，按教材口径改。

### 明确纠错

1. **2019 单选 9（社会存在范畴）**：问"不属于社会存在"，应选 **C 政治体制**（属上层建筑）。习题集选 D 地理环境，错——地理环境属于社会存在。
2. **2021 单选 12（使用价值）**：应选 **A 人与自然的关系**。习题集选 B（人与人），错——价值才反映人与人。
3. **2022 单选 16（真理标准共同错误）**：应选 **A 用认识检验认识**。习题集选 C（用实践检验），错——实践检验是正确标准，不是错误。
4. **2019 辨析 23（劳动和劳动力都可成为商品）**：应为**错误**——劳动不是商品，只有劳动力能成为商品。习题集判"正确"，且解释自相矛盾。
5. **2017 辨析 22（真理没有阶级性）**：应为**正确**——真理客观、无阶级性；带阶级性的是对真理的解释和运用。习题集判"错误"。
6. **2017 辨析 23（具体劳动和抽象劳动是两种不同性质的劳动）**：按教材应为**错误**——二者是同一劳动的两个方面，不是两种独立劳动。习题集判"正确"。
7. **2022 辨析 7（马恩认为革命在几个主要资本主义国家同时发生）**：应为**正确**（自由竞争时代的"共同胜利论"；列宁后才提一国胜利论）。习题集判"错误"。
8. **2022 多选 4（实践决定认识）**：A/B/C/D 均体现实践对认识的决定作用，应 **ABCD**。习题集给 AB。

### 存疑（按教材再核）

- **2020 单选 3（资本主义再生产实质）**：若问"生产过程"是劳动过程与价值增殖过程统一；若问"再生产过程"则是物质资料再生产与生产关系再生产的统一。题干用"再生产"，B/C 需按教材定。
- **2020 多选 13（数量上相当于平均利润的剥削收入）**：产业利润、商业利润之外，银行利润是否计入，随教材版本而异。
