# 马原·政治经济学：用人话重讲一遍

> 这份笔记只讲《马原》里的**经济学部分**（资本主义的本质及规律 + 资本主义的发展及趋势）。
> 讲义的问题是：概念密度极高、句子是"定义套定义"，看完不知道它在说什么。
> 下面我按**一条主线**、**大量类比**、**对照课本原话**的方式重讲，目标是让你"想得通"，而不是背。

---

## 0. 先给你一条主线（整章其实只讲了一件事）

整章政治经济学，本质是在回答四个连环问题：

1. **东西为什么能换东西？**（价值从哪来）
2. **钱为什么能生钱？**（资本从哪来）
3. **多出来的钱是谁创造的、被谁拿走了？**（剩余价值 / 剥削）
4. **这套系统为什么会周期性崩一次？最后会怎样？**（经济危机 / 历史趋势）

一句话概括马克思的答案：

> **财富（价值）是人的劳动创造的；在资本主义里，劳动者创造的价值 > 他得到的工资，差额被资本无偿占有；这个差额不断滚雪球，最终撞上"社会化了的生产 vs 私人占有"这堵墙，于是周期性危机，并最终被新制度取代。**

所以整章其实是一条"价值链"：

```
商品 → 货币 → 劳动力 → 剩余价值 → 资本积累 → 危机 → 垄断 → 新社会
```

下面按这条链，一段段拆。

---

## 1. 商品：一切的起点

### 1.1 商品有两个"面孔"：使用价值 和 价值

先别管定义，想一个东西：**一瓶水**。

- 它能解渴 → 这叫**使用价值**（有用性）。
- 马克思另外定义了一个由社会必要劳动时间决定的“价值”

马克思说，任何商品都同时是这两样东西，缺一不可。

**用 CS 的话类比：**

- 使用价值 ≈ 一个程序的**功能**（能不能跑、有没有用）。
- 价值 ≈ 这个程序里凝固的**人的工作量**（谁写了多久、烧了多少脑力）。

**课本原话对照：**

- **使用价值**：商品能满足人的某种需要的有用性，反映**人与自然**的关系，是**自然属性**，一切劳动产品都有（不只是商品）。
- **价值**：凝结在商品中的**无差别的一般人类劳动**（脑力和体力的耗费），是**社会属性**，**只有商品才有**。

> 注意两个坑：
>
> 1. 空气有使用价值但没价值（不是劳动产品，也不用来交换）。
> 2. "价值"在这里不是"这人对你有意义"那种价值，而是**"里面凝结了多少人类劳动"**这个非常具体的量。

**为什么不同东西能按比例交换？** 因为抛开"它是水还是面包"这些使用价值差异，它们有一个共同点：**都凝结了人的劳动**。1 个面包能换 2 瓶水，本质是"做面包花的劳动 ≈ 做 2 瓶水的劳动"。

这就是**交换价值**：价值是内容，交换价值是它表现出来的形式。

**使用价值和价值是"对立统一"：**

- **统一**：商品必须两者都有，缺一个就不叫商品。
- **对立**：对同一个人来说，**不能既占有使用价值又占有价值**。你要么自己用掉它（得到使用价值，失去价值），要么卖掉它（得到价值，失去使用价值）。——这就是"不可兼得"。

### 1.2 劳动的二重性：马克思的"源代码"

这是全书最抽象、但也是**最关键**的一个点。搞懂它，后面全通。

同一个劳动，可以从两个角度看：

| 角度                                  | 叫法         | 创造了什么 | 反映什么                     |
| ------------------------------------- | ------------ | ---------- | ---------------------------- |
| 具体干什么（厨师烤面包 / 裁缝做衣服） | **具体劳动** | 使用价值   | 人与自然的关系（自然属性）   |
| 抛开具体形式，都烧了人的脑力体力      | **抽象劳动** | 价值       | 人和人的社会关系（社会属性） |

**一句话：具体劳动创造"有用性"，抽象劳动创造"价值"。**

**类比（很关键）：**

- 一群程序员，有人写 Python、有人写 C++、有人做前端（**具体劳动不同**）。但从"都熬了夜、都烧了脑"这个层面看，他们干的都是同一件事——**付出一般人类劳动**（**抽象劳动**）。
- 正是这个"共同的抽象劳动"，让不同商品能放在一起比价。

> **为什么说劳动二重性是"理解政治经济学的枢纽"？**
> 因为它一次性解释了"商品为什么有两个面孔"：
> **劳动的二重性 → 决定了 → 商品的二因素。**
> 具体劳动 ↔ 使用价值；抽象劳动 ↔ 价值。一一对应。

### 1.3 价值量由"社会必要劳动时间"决定，而不是你花的时间

这里最容易误解。价值大小由**凝结的劳动量**决定，劳动量用**时间**衡量。但——

**不是**"你自己做了多久"，而是**"社会必要劳动时间"**：

> 在现有的**社会正常生产条件**下、以**社会平均劳动熟练程度和强度**，制造某种使用价值所需要的劳动时间。

**类比：**

- 你写一个排序算法写了 3 天，别人用标准库 3 分钟。这个任务"值多少"不按你的 3 天算，而按**社会平均水平**算。你效率低是你的事，市场不为你的低效买单。
- 所以：**个别劳动时间 > 社会必要劳动时间** → 你亏；**< 社会必要劳动时间** → 你赚（这就是后面"超额剩余价值"的种子）。

**两个必背公式方向：**

- 商品价值量与**社会必要劳动时间成正比**（花的社会必要时间越多，价值越大）。
- 商品价值量与**劳动生产率成反比**（生产率越高，单位商品花的时间越少，越便宜）。

**复杂劳动 vs 简单劳动：** 复杂劳动 = 倍加的简单劳动（培养成本更高，一小时复杂劳动 ≈ 几小时简单劳动）。这是为什么工程师时薪比搬砖高的一部分解释。

### 1.4 私有制商品经济的基本矛盾：私人劳动 vs 社会劳动

这是"商品"这一层最深的一个矛盾。

- **社会分工**让你只为别人生产（你的劳动是**社会劳动**的一部分）。
- **生产资料私有**让你自己决定生产什么、怎么生产（你的劳动又是**私人劳动**）。

矛盾在哪？——**你私下干的活，社会认不认，事先不知道。** 只有把东西**卖出去**，你的私人劳动才被"盖章"转化为社会劳动。

**类比：**

- 你写了个 App 想赚钱（私人劳动），但它到底是不是社会需要的（能否转化为社会劳动），得等**用户买单**那一刻才知道。
- 卖不出去 = 社会说"不需要"= 你的私人劳动白干。马克思把这叫"**惊险的一跃**"。

**为什么它是"基本矛盾"？**（课本三点）

1. 它决定商品经济的本质和发展过程；
2. 它是商品经济其他一切矛盾的基础；
3. 它决定商品生产者的命运（赚还是破产）。

## 2. 货币：价值的"通用接口"

### 2.1 货币是怎么来的？

不是谁发明的，是**交换发展到一定阶段自发产生的**。逻辑链：

```
物物交换（我拿米换你的布）
   ↓ 太麻烦：你要的我没有，我要的你不缺
出现"大家都愿意要"的中间商品（一般等价物）
   ↓ 慢慢固定到金银等
货币
```

**本质一句话：货币是固定充当一般等价物的商品。** 它自己也是商品（比如黄金），只是被大家公推出来当"价值显示器"。

**类比：** 物物交换像两个程序**点对点直接调用**，接口对不上就没法合作；货币相当于引入了一个**所有人都实现的标准接口/中间层**，从此任何两个东西都能通过它兑换。

### 2.2 货币的五个职能

| 职能         | 人话解释                         | 例子           |
| ------------ | -------------------------------- | -------------- |
| **价值尺度** | 给商品标价（衡量值多少）         | 标签写"￥2"    |
| **流通手段** | 当面付钱换货（一手交钱一手交货） | 买瓶水         |
| **贮藏手段** | 把钱存起来保值                   | 存金条         |
| **支付手段** | 先拿货后付钱 / 还债 / 发工资     | 赊账、还信用卡 |
| **世界货币** | 在国际间结算                     | 美元、黄金     |

### 2.3 货币带来的新矛盾

货币一出现，整个商品世界裂成**两极**：

- 一极：各种具体商品（代表**使用价值**）
- 一极：货币（代表**价值**）

于是商品内部"使用价值 vs 价值"的矛盾，**外化**成了"商品 vs 货币"的矛盾。东西只有**换成钱**，价值才算实现。

> 这也埋下了**经济危机可能性**的种子（后面第 8 节）：货币作为流通手段和支付手段，让"卖"和"买"可以脱节（我可以卖了不马上买，或者赊账），链条一断就可能出问题。

### 2.4 价值规律：市场这只"看不见的手"

**内容（必背）：**

> 商品的价值量由**社会必要劳动时间**决定；商品交换以**价值量**为基础，按**等价交换**原则进行。

**表现形式：价格围绕价值自发波动。**

- 供不应求 → 价格涨到价值以上
- 供过于求 → 价格跌到价值以下
- 但长期看，涨跌互相抵消，**价格的总趋势围绕价值**

**类比：** 这是典型的**负反馈调节系统**。价格像系统的误差信号，偏离价值时自动把资源（供给）拉回来。它不是乱跳，是**围绕中心值振荡**。

**价值规律的三个作用：**

1. **自发调节资源配置**（哪个赚钱，资源往哪流）；
2. **刺激生产力发展**（谁效率高谁赚，逼大家改进技术）；
3. **导致优胜劣汰、两极分化**（效率低的破产）。

## 3. 魔法时刻：劳动力成为商品，货币变成资本

前面讲的都还是"简单商品流通"：**W—G—W**（卖东西换钱，再拿钱买东西，目的是**用**）。

现在进入资本主义，公式变成：**G—W—G′**，其中 **G′ = G + ΔG**（钱 → 货 → 更多的钱，目的是**增殖**）。

问题来了：**钱怎么能生出更多的钱？** 等价交换不是应该"不赚不亏"吗？

### 3.1 秘密在一种特殊商品：劳动力

马克思说，答案不在流通里，而在于资本家买到了一种**特殊商品——劳动力**。

**劳动力成为商品要有两个条件（必背）：**

1. 劳动者是**自由人**，能自由支配自己的劳动力；
2. 劳动者**一无所有**，没有生产资料，除了卖劳动力没别的活路。

> 第一个条件让他"能卖"，第二个条件让他"不得不卖"。

### 3.2 劳动力商品的特殊性：它的使用价值能"下金蛋"

普通商品：你买来用掉，价值就消耗了（面包吃了就没了）。
**劳动力不一样**：

> **劳动力的使用价值，就是它能创造价值，而且创造出的价值 > 劳动力自身的价值。**

**类比：**

- 你花 100 块租了一台"会自己印钞"的机器，它一天能印出 200 块。租金（劳动力价值）100，产出 200，多出的 100 就是**剩余价值**。
- 劳动力的"工资"就是租金，"干活创造的价值"就是产出。

**劳动力的价值由什么决定？** 由"维持、发展、延续劳动力所需生活资料的价值"决定，包括三部分：

1. 维持**劳动者本人**生存的生活资料价值；
2. 维持**劳动者家属**（延续劳动力）的生活资料价值；
3. **教育培训**费用。

（另外还包含一个"历史和道德因素"，即不同国家/时代"体面生活"的标准不同。）

### 3.3 于是货币变成了资本

**资本 = 能带来剩余价值的价值。**

- 资本家买的是**劳动力**，不是"劳动"。（这个区分很重要，见第 7 节工资部分。）
- 买到劳动力后，在使用（干活）过程中，不仅收回了付出去的价值，还多出一个增殖额——**剩余价值**。
- **一旦货币能带来剩余价值，货币就变成了资本。**

> 一句话：**钱本身不会生钱，是"钱买到劳动力→劳动力干活创造更多价值"这个循环在生钱。**

## 4. 解剖剩余价值：资本家怎么"拧螺丝"

### 4.1 剩余价值到底是什么

工人一天的工作时间，被马克思切成两段：

```
工作日 = 必要劳动时间 + 剩余劳动时间
         （为自己干）      （为资本家白干）
```

- **必要劳动**：创造的价值 = 自己的工资（劳动力价值），这部分是"还本"。
- **剩余劳动**：创造的价值被资本家**无偿占有**，这就是**剩余价值**。

**定义（必背）：**

> 剩余价值是雇佣工人所创造的、被资本家无偿占有的、**超过劳动力价值**的那部分价值，是剩余劳动的凝结，体现资本家对工人的**剥削关系**。

**类比：** 你打工一天 8 小时，前 4 小时挣够了自己的工资，后 4 小时在给老板"白干"。老板付你的是"劳动力的价钱"，拿走的却是"你全部劳动成果"。

### 4.2 不变资本 c 和可变资本 v（关键区分）

资本按"在剩余价值生产中起什么作用"分成两块：

| 名称         | 形态                             | 作用                                           | 符号  |
| ------------ | -------------------------------- | ---------------------------------------------- | ----- |
| **不变资本** | 厂房、机器、原材料等**生产资料** | 只把原有价值**转移**到新产品，**不改变价值量** | **c** |
| **可变资本** | 用来**购买劳动力**的钱           | 能**增殖**，是剩余价值的真正来源               | **v** |

**为什么叫"不变"？** 因为机器、原料只是"搬运价值"，不会凭空变多。**只有活劳动（工人）能创造出比自身价值更多的东西。**

**类比：**

- 不变资本 = 原材料和工具，像"搬运工"，价值原样搬进产品。
- 可变资本 = 雇来的人，像"炼金术"，能炼出比工资更多的东西。

**这个区分的意义（必背）：**

1. 揭示剩余价值的**唯一源泉是雇佣工人的剩余劳动**（既不是全部资本，也不是机器创造的）；
2. 为计算**剥削程度**提供依据。

**剩余价值率（剥削程度）：**

$$m' = \frac{m}{v} = \frac{\text{剩余劳动}}{\text{必要劳动}} = \frac{\text{剩余劳动时间}}{\text{必要劳动时间}}$$

### 4.3 提高剥削的三种方式（必考，容易混）

| 方式             | 怎么干                                              | 前提             | 关系                   |
| ---------------- | --------------------------------------------------- | ---------------- | ---------------------- |
| **绝对剩余价值** | **延长工作日** / 提高劳动强度                       | 必要劳动时间不变 | 最简单粗暴（加班）     |
| **相对剩余价值** | **缩短必要劳动时间**（提高全社会劳动生产率）        | 工作日长度不变   | 全社会一起变强         |
| **超额剩余价值** | 个别企业提高生产率，**个别价值 < 社会价值**，赚差价 | 别人还没跟上     | 相对剩余价值的**原因** |

**三者关系（一句话记住）：**

> 每个资本家都想赚**超额剩余价值**（我比你便宜，但按市场价卖）→ 大家都拼命改进技术 → **全社会劳动生产率提高** → 生活资料变便宜 → 劳动力价值下降 → 必要劳动时间缩短 → 于是就生产出了**相对剩余价值**。

**超额剩余价值是"原因"，相对剩余价值是"结果"。**

### 4.4 "无人工厂"、机器人会创造价值吗？（常考辨析）

**马克思的答案：不会。**

- 机器人、自动化生产线本质仍是**物化劳动 / 不变资本**，只能**转移价值**，不能创造新价值。
- 自动化只是资本家获取**超额剩余价值**的手段。
- **剩余价值的唯一源泉，仍然是雇佣工人的剩余劳动。**

> 逻辑：机器再先进，也是人设计、生产、维护的；而且"价值"的定义就是"凝结的人类劳动"，机器本身不提供活劳动，自然不新增价值。

## 5. 滚雪球：资本积累

### 5.1 资本积累的本质和源泉

资本家不会把剩余价值全花掉，而是拿一部分**再投资**，扩大生产规模。这叫**资本积累**。

**本质（必背）：**

> 资本家不断用**无偿占有的剩余价值**来扩大资本规模，进一步扩大和加强对工人的剥削和统治。

**源泉：剩余价值。**（剩余价值是资本积累的源泉，资本积累又反过来扩大剥削——正反馈，滚雪球。）

### 5.2 资本有机构成 c:v

- **技术构成**：生产资料数量 : 劳动力数量（由技术水平决定）。
- **价值构成**：不变资本 : 可变资本 = c : v。
- **有机构成**：**由技术构成决定、并反映技术构成变化的**价值构成，记作 **c : v**。

**人话：** 随着技术进步，机器越来越多、需要的工人相对越来越少，于是 c 涨、v 相对降，**c:v 不断提高**。

### 5.3 后果：机器排挤人 → 相对过剩人口

c:v 提高 = 更"资本密集"、更少"劳动密集" → 对劳动力的需求相对减少 → 出现**相对过剩人口（失业大军）**。这不是人真的多余，而是**相对于资本增殖的需要**显得多余。

**还有：** 财富向资本一端集中，贫困向劳动一端集中 → **两极分化**。

### 5.4 历史趋势（"两个必然"的思想源头）

资本积累 → 生产越来越社会化 + 财富越来越集中到少数人 → 基本矛盾越来越尖锐 → **资本主义必然灭亡、社会主义必然胜利**。

（这就是后面"科学社会主义"的理论基石之一。）

## 6. 资本的"血液循环"：循环、周转、再生产

这一节讲资本怎么"转起来"，像看一个系统的运行。

### 6.1 产业资本的三种形态和三阶段

资本要转一圈，要换三次"马甲"：

```
G — W … P … W′ — G′
货币资本 → 生产资本 → 商品资本 → (更多)货币
```

| 阶段     | 形态     | 干什么                           |
| -------- | -------- | -------------------------------- |
| **购买** | 货币资本 | 买生产资料和劳动力               |
| **生产** | 生产资本 | 工人干活，生产出含剩余价值的产品 |
| **售卖** | 商品资本 | 把商品卖掉，收回更多货币         |

**正常运转的前提（必背两条）：**

1. **空间上并存**：三种形态必须同时按比例存在（不能全压在一头）。
2. **时间上继起**：三个阶段必须依次连续，不能断档。

**类比：** 像一条流水线，三个工位必须**同时都有人**（并存），而且**依次流畅衔接**（继起）。任何一个环节卡住，整条线就停。

### 6.2 资本周转：转得越快，赚得越多

**周转** = 资本周而复始、不断重复的循环。

**影响周转快慢的两个关键因素：**

1. **周转时间**（越短越快）；
2. **固定资本 vs 流动资本**的构成（流动资本周转快，固定资本周转慢）。

**结论：** 加快周转 → 同样时间里剩余价值生产次数更多 → 赚更多。

### 6.3 社会再生产：整个社会是一个"大工厂"

**核心问题：社会总产品的"实现"**，包括两件事：

- **价值补偿**：东西该卖的卖掉了（收回钱）；
- **实物补偿**：该买的生产资料和消费资料买到了（能继续生产）。

社会生产分**两大部类**：

- **第 I 部类**：生产**生产资料**（机器、原料）
- **第 II 部类**：生产**消费资料**（衣服、食品）

**要求：** 两大部类之间、各部类内部各部门之间，必须保持**一定比例关系**。

**类比：** 像两条互相供货的生产线：I 给 II 造机器，II 给 I 的工人造消费品。比例一旦失衡（I 造太多机器没人买 / II 造太多消费品工人买不起），系统就出问题——这直接通向下一节的危机。

## 7. 钱是怎么分的：工资与利润

### 7.1 工资的本质：一场"障眼法"

**表面现象：** 我干一天活，老板给我一天的钱，看起来是"**劳动的价格**"或"全部劳动的报酬"。

**本质（必背）：**

> 工资是**劳动力的价值或价格**，不是"劳动的价格"。

**为什么这个区别重要？** 因为如果工资真是"全部劳动的报酬"，那就不存在"白干的部分"，剥削就看不见了。

**类比：** 你把"租机器的钱"说成"机器产出的全部钱"，中间被抽走的部分就被藏起来了。工资把"必要劳动和剩余劳动的界限"模糊掉了，从而**掩盖了剥削关系**。

（工资形式：**计时工资**、**计件工资**。）

### 7.2 剩余价值 → 利润：又一层"马甲"

现实中，资本家不觉得剩余价值是"工人创造的"，而觉得是"**我全部投资（c+v）带来的回报**"。于是：

- **剩余价值 m**（本质，是 **v** 的产物）
- 转化为 **利润 p**（形式，被看作 **(c+v)** 的产物）

$$m \text{ 和 } p：\text{源泉相同、量上相等；} m \text{ 是本质，} p \text{ 是形式。}$$

**意义：** 一旦变成利润，剩余价值和"可变资本 v"的关系就被掩盖了——好像利润是"钱自己生出来的"，而不是"工人剩余劳动创造的"。

## 8. 系统 Bug：资本主义基本矛盾与经济危机

### 8.1 基本矛盾

> **生产社会化** 和 **生产资料资本主义私人占有** 之间的矛盾。

拆开看：

- **生产社会化**：生产越来越是**全社会协作**的结果（一个大产品，成千上万人分工合作）。
- **私人占有**：但生产资料和成果却归**少数资本家私人**所有。

**类比（很贴切）：**

> 这就像**一个超大型分布式系统，由全社会共同协作运行，但收益和决策权却归少数私人**。协作要求"按整体需要来规划"，私人占有却要求"按私人利润来决策"——两套逻辑根本冲突。

### 8.2 经济危机：本质是"相对过剩"

- **本质特征：生产相对过剩**。
- **注意"相对"**：不是东西多到人真的用不完（绝对过剩），而是**相对于劳动人民有支付能力的需求**显得过剩——**东西很多，但穷人买不起**。

**危机的可能性 vs 现实性：**

- **可能性**：来自货币作为**流通手段和支付手段**（买卖可以脱节）。
- **根本原因**：**资本主义基本矛盾**。它具体表现为两对矛盾：
  1. **生产无限扩大的趋势** vs **劳动人民有支付能力的需求相对缩小**（生产拼命扩张，工人却没那么多钱买）；
  2. **个别企业生产的有组织性** vs **整个社会生产的无政府状态**（每个厂内部井井有条，但全社会没人统一协调）。

**类比：** 一个**正反馈失控**——生产越扩张越想扩张，但消费能力跟不上，库存越堆越多，最终链条断裂（危机）。

### 8.3 周期性：崩溃—重启的循环

```
危机 → 萧条 → 复苏 → 高涨 →（又）危机 …
```

- 四阶段相互联系，**危机阶段是基本阶段，也是必经阶段**。
- 这是由基本矛盾运动的**阶段性**决定的（矛盾激化→危机→强制调整→再积累→再激化）。

## 9. 资本主义的"升级版"：垄断资本主义

前面讲的是"自由竞争"阶段。发展到后面，变成**垄断**。

### 9.1 垄断不能消除竞争

垄断是从自由竞争中长出来的，但它**消除不了竞争**，反而让竞争更复杂、更激烈。原因（必背三点）：

1. 垄断**没有消除产生竞争的经济条件**；
2. 垄断**必须通过竞争来维持**；
3. 社会生产**复杂多样**，任何垄断组织都包不下全部生产。

**垄断竞争的新特点：**

- **目的**：不是普通利润，而是**高额垄断利润**、巩固垄断地位；
- **手段**：不只经济手段，还有非经济手段（更复杂残酷）；
- **范围**：从国内扩展到国际、遍及各个领域。

### 9.2 金融资本与金融寡头

- **金融资本** = **工业垄断资本 + 银行垄断资本**融合而成。
  - 融合途径：**金融联系、资本参与、人事参与**。
- **金融寡头** = 操纵国民经济命脉、实际控制国家政权的**少数垄断资本家/集团**。

**金融寡头怎么统治（必背）：**

1. **经济上**：靠"**参与制**"（掌握一定股票，层层控制企业）；
2. **政治上**：靠与政府"**个人联合**"（政商旋转门）；
3. 还通过**政策咨询机构、掌控新闻科教文化**等影响内政外交。

### 9.3 垄断利润与垄断价格

- **垄断利润**：凭借垄断地位获得的、**超过平均利润**的高额利润。

- **归根到底来自**无产阶级和其他劳动人民创造的**剩余价值**。具体来源四点：

  1. 加强对本国劳动人民的剥削；
  2. 控制市场，攫取非垄断企业的利润；
  3. 剥削掠夺其他国家人民；
  4. 通过国家政权做有利于垄断资本的再分配。

- **垄断价格** = **成本价格 + 平均利润 + 垄断利润**。

  - 形式：**垄断高价**（卖）和**垄断低价**（买）。
  - **没有否定价值规律**，只是价值规律在垄断阶段的具体表现。

### 9.4 国家垄断资本主义

**国家政权 + 私人垄断资本**结合。

**五种主要形式：**

1. 国家所有并直接经营的企业；
2. 国家与私人共有、合营企业；
3. 国家参与私人垄断资本的再生产（订货、补贴等）；
4. **宏观调节**（财政、货币政策调总供给总需求）；
5. **微观规制**（法律规范市场、反垄断、保护消费者）。

**实质（必背）：** 私人垄断资本**利用国家机器为自己服务**的手段。
**性质没变**：它是资本主义**制度内**的经济关系调整，**没有根本消除基本矛盾**。

### 9.5 经济全球化

**表现（四点）：**

1. 国际分工进一步深化；
2. 贸易全球化；
3. 金融全球化；
4. 企业生产经营全球化（跨国公司）。

**影响：**

- **积极**：给发展中国家带来技术、管理经验、就业、贸易和跨国公司发展机会。
- **消极**：发达国家与发展中国家**地位和收益不平等**；加剧资源短缺和环境污染；增加经济风险。

### 9.6 当代资本主义的新变化及其本质（必考）

**变化表现：** 经济调节机制和危机形态变化、政治制度变化（民主形式扩大、法制加强、改良主义政党影响扩大）等。

**本质（关键结论，别答错）：**

1. 变化从根本上说是**人类社会发展一般规律和资本主义经济规律作用的结果**；
2. 变化是**在资本主义制度基本框架内**的变化，**不意味着根本性质改变**；
3. **没有克服基本矛盾**，也没有改变马克思主义关于资本主义基本论断的科学性。

> 判断标准：只要**生产资料私有制**和**雇佣劳动**还在，只要**剩余价值规律**还在起作用，资本主义生产关系的**根本性质就不会变**。

## 12. 附：几个最容易想岔的地方

1. **"价值"不是"有用/有意义"**，而是"凝结的人类劳动量"。别用日常语义去理解。
2. **不是"你花的时间越多越值钱"**，而是按**社会必要劳动时间**算。低效不值钱。
3. **机器不创造价值**，只转移价值；机器人、"无人工厂"也一样。剩余价值只来自活劳动。
4. **工资不是"劳动的报酬"**，是"劳动力的价格"。这是掩盖剥削的关键点。
5. **"过剩"是相对过剩**：不是东西多得用不完，是穷人买不起。
6. **垄断没有消灭价值规律**，垄断价格仍以价值为基础。
7. **当代资本主义"变了"不等于"本质变了"**：私有制 + 雇佣劳动 + 剩余价值规律还在，性质就没变。
