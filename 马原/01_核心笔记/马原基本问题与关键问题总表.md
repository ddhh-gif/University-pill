## 2. 唯物论

| 问题 | 标准表述 | 备注 |
|---|---|---|
| 哲学基本问题 | **思维和存在的关系问题**（物质和意识的关系问题） | 恩格斯首次明确提出 |
| 哲学基本问题的两个方面 | ①思维和存在何者第一性 → **唯物/唯心**；②思维和存在有无同一性 → **可知论/不可知论** | 选择题常单考其中一方面 |
| 哲学的两个对子 | **唯物主义 vs 唯心主义**；**辩证法 vs 形而上学** | 不是“唯物 vs 形而上学” |
| 唯物主义的三种历史形态 | **古代朴素唯物主义、近代形而上学唯物主义、辩证唯物主义** | 近代形态又称机械唯物主义 |
| 唯心主义的两种形式 | **主观唯心主义、客观唯心主义** | 主观唯心：心外无物；客观唯心：理在事先、绝对精神 |
| 物质的唯一特性 | **客观实在性** | 不是具体形态、不是原子 |
| 物质的根本属性 / 存在方式 | **运动** | 运动绝对，静止相对 |
| 运动的存在形式 | **时间和空间** | 时空是运动着的物质的存在形式 |
| 意识的本质 | **人脑的机能和属性，客观世界的主观映象** | 客观内容 + 主观形式 |
| 意识的能动作用 | **目的性/计划性、创造性、指导实践、控制人体生理活动** | 意识不能直接改变客观事物 |
| 世界统一性原理 | **世界的真正统一性在于它的物质性** | 唯物主义一元论 |
| 社会生活的本质 | **实践** | 马克思《关于费尔巴哈的提纲》 |
| 人与自然关系的基础/中介 | **实践**；人与自然和谐共生 | 不是“人决定自然” |
| 规律 | **事物内部本质的、必然的、稳定的联系** | 规律具有客观性 |
| 客观规律性与主观能动性 | **尊重客观规律是发挥主观能动性的前提；发挥主观能动性是认识和利用规律的必要条件** | 二者统一 |

## 4. 认识论

| 实践的基本特征 | **直接现实性（客观物质性）、自觉能动性、社会历史性** | 不同教材第一项表述略有差异 |

| 认识的本质 | **主体在实践基础上对客体的能动反映** | 不是直观、消极的反映 |

| 真理的本质/属性 | **客观性；绝对性；相对性；具体性** | 客观性是真理的本质属性 |

| 价值 | **客体对主体需要的满足/意义** | 价值具有主体性、客观性、多维性、社会历史性 |
| 价值评价的特点 | **以主客体的价值关系为对象；结果依主体而转移；正确与否依赖对客体和主体的正确认识** | 价值评价不是主观随意 |
| 真理尺度与价值尺度 | **真理原则与价值原则；人类活动的两个基本原则** | 坚持真理尺度和价值尺度的统一 |
| 自由与必然 | **自由是对必然的认识和对客观世界的改造** | 自由是具体的、历史的 |
| 认识世界与改造世界 | **统一；改造客观世界与改造主观世界** | 认识世界是为了改造世界 |
| 实事求是 | **马克思主义认识论的根本要求；党的思想路线的核心** | 一切从实际出发 |

| 社会基本矛盾 | **生产力与生产关系、经济基础与上层建筑的矛盾** | 社会发展的根本动力 |
| 社会形态更替的特点 | **统一性多样性、必然性与选择性、前进性曲折性** | 统一性通过多样性实现 |
| 阶级斗争 | **阶级社会发展的直接动力** | 不是一切社会形态的直接动力 |
| 社会革命 | **社会形态更替的重要手段/根本变革** | 革命是历史的火车头 |
| 改革 | **社会主义制度的自我完善和发展；社会主义社会发展的直接动力/强大动力** | 不是社会革命 |

| 人民群众 | **历史的创造者；历史发展的决定力量** | 不是英雄创造历史 |
| 人的本质 | **一切社会关系的总和** | 不是抽象的人性 |

## 6. 政治经济学

| 问题 | 标准表述 | 备注 |
|---|---|---|
| 政治经济学的枢纽 | **劳动二重性** | 理解政治经济学的枢纽 |
| 商品二因素 | **使用价值和价值** | 使用价值是自然属性，价值是社会属性 |
| 劳动二重性 | **具体劳动和抽象劳动；具体劳动创造使用价值，抽象劳动形成价值** | 劳动二重性决定商品二因素 |
| 价值量 | **由社会必要劳动时间决定；与劳动生产率成反比** | 社会必要劳动时间是在现有社会正常生产条件下、在社会平均劳动熟练程度和劳动强度下制造某种使用价值所需要的劳动时间 |
| 价值规律 | **内容：价值量由社会必要劳动时间决定，等价交换；表现形式：价格围绕价值波动；作用：调节资源配置、刺激生产力、调节收入分配** | 也有消极后果 |
| 货币的本质和职能 | **一般等价物；价值尺度、流通手段、贮藏手段、支付手段、世界货币** | 价值尺度和流通手段是基本职能 |
| 私有制商品经济的基本矛盾 | **私人劳动和社会劳动的矛盾** | 通过交换解决 |
| 劳动力成为商品的基本条件 | **劳动者有人身自由；劳动者一无所有** | 两个基本条件 |
| 劳动力商品的价值和使用价值 | **价值由生活资料价值等决定；使用价值能创造比自身价值更大的价值** | 劳动力商品使用价值的特殊性 |
| 资本主义生产过程的二重性 | **劳动过程和价值增殖过程的统一** | 价值增殖过程是超过一定点而延长了的价值形成过程 |
| 不变资本和可变资本 | **划分依据：资本不同部分在价值增殖中的作用不同** | c 不变资本，v 可变资本 |
| 剩余价值的本质 | **雇佣工人剩余劳动创造的、被资本家无偿占有的超过劳动力价值的价值** | 本质是资本家对工人的剥削关系 |
| 剩余价值的生产方法 | **绝对剩余价值、相对剩余价值；超额剩余价值** | 相对剩余价值是全社会劳动生产率提高的结果 |
| 资本积累的本质和源泉 | **剩余价值资本化；源泉是剩余价值** | 资本积累导致相对过剩人口 |
| 资本有机构成 | **c:v；资本有机构成提高导致相对过剩人口** | 由资本技术构成决定并反映技术构成变化的资本价值构成 |
| 资本循环 | **三阶段：购买、生产、售卖；三职能：货币资本、生产资本、商品资本** | 连续进行条件：空间并存、时间继起 |
| 资本周转 | **固定资本和流动资本；周转速度影响年剩余价值率** | 周转越快，年剩余价值率越高 |
| 社会再生产核心问题 | **社会总产品的实现（价值补偿 + 实物补偿）** | 两大部类比例关系 |
| 工资的本质 | **劳动力价值/价格，不是劳动的价值/价格** | 工资掩盖了剥削关系 |
| 利润的本质 | **剩余价值的转化形式；平均利润、生产价格** | 利润率平均化 |
| 剩余价值的分配 | **商业利润、利息、地租** | 各资本家集团瓜分剩余价值 |
| 资本主义基本矛盾 | **生产社会化和生产资料资本主义私人占有之间的矛盾** | 资本主义一切矛盾的总根源 |
| 资本主义基本经济规律 | **剩余价值规律** | 追求剩余价值是资本主义生产的直接目的 |
| 经济危机的实质和根源 | **实质：生产相对过剩；根源：资本主义基本矛盾** | 不是绝对过剩 |
| 垄断资本主义的基本特征和实质 | **五个基本特征；实质是垄断资本凭借垄断地位获取高额垄断利润** | 垄断没有消除竞争 |
| 国家垄断资本主义的实质 | **私人垄断资本利用国家机器为自己服务；没有改变垄断资本主义性质** | 没有根本消除基本矛盾 |
| 经济全球化 | **表现：生产、贸易、金融、企业经营全球化；动因：科技进步、跨国公司、市场经济体制；后果：双刃剑** | 发达国家主导，发展中国家机遇与挑战并存 |
| 两个必然 / 两个决不会 | **资本主义必然灭亡、社会主义必然胜利；旧社会形态在生产力充分发挥前不会灭亡，新生产关系在物质条件成熟前不会出现** | “两个必然”讲趋势，“两个决不会”讲条件 |

## 8. 易混辨析

### 8.1 “基本问题”四连

| 表述 | 标准答案 |
|---|---|
| 哲学基本问题 | **思维和存在的关系问题** |
| 社会历史观基本问题 | **社会存在和社会意识的关系问题** |
| 认识论基本问题（常表述） | **实践和认识的关系问题** |
| 马克思主义首要的基本观点 | **实践观点** |

### 8.2 “实质 / 核心 / 精髓 / 焦点”

- **实质**：辩证否定的实质 = **扬弃**；经济危机的实质 = **生产相对过剩**；国家垄断资本主义的实质 = **私人垄断资本利用国家机器为自己服务**。
- **核心**：唯物辩证法的实质和核心 = **对立统一规律**；上层建筑的核心 = **国家政权**；科学社会主义是马克思主义的**核心/归宿**。
- **精髓**：矛盾问题的精髓 = **矛盾普遍性和特殊性的关系**。
- **焦点**：唯物辩证法与形而上学对立的焦点 = **是否承认矛盾，是否承认内部矛盾是事物发展的根本动力**。

### 8.3 “总特征 / 实质核心”

- 唯物辩证法的**总特征** = **联系和发展**。
- 唯物辩证法的**实质和核心** = **对立统一规律**。
- 两者不能互换：总特征是“世界怎么样”，实质核心是“辩证法的根本规律”。

### 8.4 “基本矛盾 / 主要矛盾”

- **社会基本矛盾** = 生产力与生产关系、经济基础与上层建筑的矛盾；贯穿人类社会始终。
- **主要矛盾** = 在某一阶段占支配地位、起决定作用的矛盾；会随阶段变化。
- 资本主义基本矛盾 = **生产社会化与生产资料资本主义私人占有**。
- 社会主义社会基本矛盾 = 仍然是两对矛盾，但**非对抗性**，通过改革解决。

### 8.5 “根本动力 / 直接动力 / 重要动力”

- **根本动力** = **社会基本矛盾**。
- **直接动力（阶级社会）** = **阶级斗争**。
- **直接动力（社会主义社会）** = **改革**。
- **重要动力** = 革命、改革、科学技术、文化等。
- 选择题问“根本动力”不要选阶级斗争；问“阶级社会直接动力”才选阶级斗争。

### 8.6 “决定力量 / 决定作用”

- 社会存在的**决定力量** = **物质生产方式**，不是地理环境、人口因素。
- 生产力是社会发展的**最终决定力量**。
- 社会存在**决定**社会意识；社会意识**反作用**于社会存在。
- 不能说“社会意识决定社会生活”，也不能说“社会存在决定自然存在”。

### 8.7 “唯一特性 / 根本属性”

- 物质的**唯一特性** = **客观实在性**。
- 物质的**根本属性** = **运动**。
- 运动的存在形式 = **时间和空间**。
- 三者不能混。

### 8.8 “理论基础 / 主要内容 / 核心归宿”

- 马克思主义哲学 = **理论基础**。
- 马克思主义政治经济学 = **主要内容**。
- 科学社会主义 = **核心/归宿**。
- 社会主义从空想到科学的两大理论基础 = **唯物史观 + 剩余价值学说**，不是“空想社会主义”。

### 8.9 “资本主义基本矛盾 / 社会主义社会基本矛盾”

- 资本主义基本矛盾 = **生产社会化与生产资料资本主义私人占有**，是对抗性矛盾。
- 社会主义社会基本矛盾 = **生产力与生产关系、经济基础与上层建筑**，是非对抗性矛盾。
- 社会主义社会基本矛盾可以通过**改革**自我完善，不需要社会革命。

### 8.10 “垄断资本主义基本特征 / 国家垄断资本主义实质”

- 垄断资本主义的**五个基本特征**：垄断组织起决定作用；金融资本和金融寡头；资本输出；国际垄断同盟；列强瓜分世界。
- 国家垄断资本主义的**实质**：私人垄断资本利用国家机器为自己服务，**没有改变垄断资本主义性质**。
- 垄断没有消除竞争，而是使竞争更复杂、更激烈。

### 8.11 “两个必然 / 两个决不会”

- **两个必然**：资本主义必然灭亡、社会主义必然胜利。
- **两个决不会**：旧社会形态在它所能容纳的全部生产力发挥出来以前不会灭亡；新生产关系在物质条件成熟以前不会出现。
- 前者讲**趋势**，后者讲**条件**，不能只背一个。

### 8.12 社会存在 / 自然存在 / 社会生活 / 社会关系

| 概念 | 笔记口径 |
|---|---|
| 社会存在 | 社会物质生活条件：**地理环境、人口因素、物质生产方式** |
| 自然存在 | 自然界；**社会存在 ≠ 整个自然界**，地理环境只是进入社会存在的那部分自然 |
| 社会生活 | 包括物质生活和精神生活；**社会生活的本质是实践** |
| 社会关系 | 人们在实践中形成的各种关系；**生产关系是最基本的社会关系**，生产关系由生产力决定 |
| 正确公式 | **社会存在决定社会意识**；不是社会意识决定社会生活，也不是社会存在决定自然存在 |

## 9. 一条记忆链

> **哲学基本问题**（思维/存在）→ **社会历史观基本问题**（社会存在/社会意识）→ **实践**（社会生活本质、认识基础）→ **矛盾**（唯物辩证法实质核心）→ **真理**（实践是唯一标准）→ **社会基本矛盾**（根本动力）→ **资本主义基本矛盾**（生产社会化/私人占有）→ **两个必然**（资本主义灭亡、社会主义胜利）。

背的时候按这条链往下挂，不要孤立背“基本问题”四个字。
