# 马原·被批判的"主义"与人物总表

> 用途：选择题"贴标签"、辨析题"定性 + 错在哪"、论述题"批判继承"。
> 口径：以高教版《马克思主义基本原理》为主；标 **【扩展】** 的是教材外常考补充。
> 一条铁律：马原批判任何观点都是三步——**先定性（哪家）→ 再指出割裂了什么 → 最后给正确观点**。

---

## 0. 先立四把尺（贴标签用）

| 标签 | 判断标准 | 题干关键词 |
|---|---|---|
| **A 唯物论** | 物质第一性、意识第二性 | 物质决定意识、客观实在、实践、从实际出发 |
| **B 辩证法** | 联系、发展、全面、矛盾 | 联系发展、对立统一、量变质变、否定之否定 |
| **C 形而上学** | 孤立、静止、片面、否认矛盾 | 孤立静止片面、外因论、绝对化、一刀切 |
| **D 决定论** | 承认因果必然性、规律 | 规律、必然、因果；绝对化 → 机械决定论/宿命论 |
| （附）**唯心论** | 意识第一性、物质第二性 | 心外无物、存在即被感知、绝对精神、理念 |

> ⚠️ A 与 B 不是对立项：一句话可以同时是 **A+B（唯物辩证法）**。单选看材料"强调的侧面"：
> 讲本原 → A；讲联系发展矛盾 → B；讲静止孤立 → C；讲因果规律 → D。

## 1. 哲学基本问题：唯物 vs 唯心

### 1.1 唯物主义三形态

| 形态 | 代表人物 | 核心主张 | 马原评价 |
|---|---|---|---|
| 古代朴素唯物主义 | 泰勒士（水）、赫拉克利特（火）、德谟克利特（原子）、王充、范缜、荀子、王夫之 | 世界由某种具体物质形态构成 | 方向对，但**直观、缺乏科学抽象**；社会历史观仍是唯心 |
| 近代机械唯物主义（形而上学唯物主义） | 培根、霍布斯、洛克；拉美特利、狄德罗、爱尔维修、霍尔巴赫；费尔巴哈 | 世界统一于原子；人是机器 | 唯物但**机械性、形而上学性、不彻底性（唯心史观）** |
| 辩证唯物主义 | 马克思、恩格斯 | 物质是客观实在；实践 | 最高形态 |

### 1.2 唯心主义两型

| 类型 | 代表人物 | 标志性命题 | 批判要点 |
|---|---|---|---|
| 主观唯心主义 | 贝克莱、陆九渊、王阳明、费希特、马赫 | "存在就是被感知""心外无物""宇宙便是吾心""自我设定非我" | 夸大主观精神 → **唯我论** |
| 客观唯心主义 | 柏拉图、毕达哥拉斯、黑格尔、朱熹、董仲舒、老子/庄子（"道"） | "理念""数""绝对精神""理在事先""天人感应""道生万物" | 把客观精神当第一性 → **与宗教神学同构** |

> 老子归属教材有分歧：主流按"道"是客观精神处理为客观唯心，同时承认其朴素辩证法。

### 1.3 其他"论"

| 主义/观点 | 人物 | 主张 | 马原定性 |
|---|---|---|---|
| 二元论 | 笛卡尔 | 物质与精神是两个独立实体 | 动摇于唯物唯心之间，最终倒向唯心 |
| 可知论 | 黑格尔、费尔巴哈、马哲 | 世界可以被认识 | 马哲是实践基础上的彻底可知论 |
| 不可知论 | 休谟、康德 | 只能认识现象，"物自体"不可知 | 否认认识能力、脱离实践，给信仰留地盘 |
| 怀疑论 | 皮浪 | 一切不可确定、悬置判断 | 相对主义，取消真理 |
| 信仰主义 | 德尔图良、奥古斯丁、托马斯·阿奎那 | "正因为荒谬，我才相信" | 反理性、反科学 |
| 唯意志论 | 叔本华、尼采 | 世界是意志/权力意志 | 夸大意志，导致唯心史观 |
| 生命哲学/直觉主义 | 柏格森 | 靠直觉把握"生命之流" | 反理性主义 |
| 泛神论 | 布鲁诺、斯宾诺莎 | 神即自然 | 有唯物主义倾向，但仍披神学外衣 |

## 2. 辩证法 vs 形而上学

| 主义/观点 | 人物 | 主张 | 马原批判 |
|---|---|---|---|
| 形而上学 | 近代机械论者 | 孤立、静止、片面；否认矛盾；外因论 | 与辩证法根本对立 |
| 唯心辩证法 | 黑格尔 | 有辩证法，但倒立在"绝对精神"上 | 吸收合理内核，批判其唯心体系 |
| 朴素辩证法 | 赫拉克利特、老子 | "人不能两次踏入同一条河流" | 直观、不系统 |
| 诡辩论 | 芝诺（飞矢不动、阿基里斯追龟）、克拉底鲁（"一次也不能踏入"）、公孙龙（白马非马） | 割裂运动与静止、个别与一般 | 主观任意、偷换概念 |
| 相对主义 | 克拉底鲁、普罗泰戈拉（"人是万物的尺度"） | 否认确定性 | 夸大相对性，走向不可知 |
| 绝对主义 | — | 否认发展、把事物绝对化 | 形而上学 |
| 折中主义 | — | 无原则调和、东拼西凑 | 冒充辩证法 |
| 庸俗进化论 | 斯宾塞 | 只承认量变、渐变 | 否认质变和飞跃 |
| 循环论 | 维科、斯宾格勒、汤因比 | 历史周而复始 | 否认前进上升 |
| 外因论 | — | 发展全靠外部推动 | 否认内因是根据 |

## 3. 认识论上的各种"论"

| 主义/观点 | 人物 | 主张 | 马原批判 |
|---|---|---|---|
| 唯心主义先验论 | 柏拉图（回忆说）、笛卡尔（天赋观念）、康德（先验）、孔子（"生而知之"） | 认识先天就有 | 否认实践是认识来源 |
| 旧唯物主义直观反映论 | 费尔巴哈 | 认识是消极、直观的反映 | 脱离实践、脱离辩证法、不懂能动性 |
| 唯物主义经验论 | 培根、霍布斯、洛克（白板说） | 一切知识来自感觉经验 | 有合理成分，但片面夸大感性 |
| 唯心主义经验论 | 贝克莱、休谟 | 经验即感觉 | 走向主观唯心/不可知 |
| 唯理论 | 笛卡尔、斯宾诺莎、莱布尼茨 | 理性是知识唯一来源 | 夸大理性、贬低感性；"天赋观念"是唯心的 |
| 实用主义真理观 | 皮尔士、詹姆斯、杜威 | "有用即真理" | 以效用代替客观性 → 主观唯心 |
| 马赫主义/经验批判主义 | 马赫、阿芬那留斯 | 世界是"感觉的复合" | 主观唯心；列宁《唯物主义和经验批判主义》批判 |
| 实证主义 | 孔德 | 只研究现象，不问本质 | 拒斥本质和规律 |
| 约定论 | 彭加勒 | 科学定律是人为约定 | 否认客观真理 |
| 相对主义真理观 | — | 真理只是相对的 | 否认真理客观性、绝对性 |
| 教条主义/本本主义 | 王明 | 照搬书本和外国经验 | 主观与客观相分离 |
| 经验主义 | — | 轻视理论、迷信局部经验 | 把局部经验当普遍真理 |

## 4. 历史观

| 主义/观点 | 人物 | 主张 | 马原批判 |
|---|---|---|---|
| 唯心史观 | 黑格尔、费尔巴哈、卡莱尔 | 精神/英雄决定历史 | 没找到历史发展的客观规律和物质根源 |
| 英雄史观 | 卡莱尔（"历史是英雄的传记"） | 少数英雄创造历史 | 否认人民群众是历史创造者 |
| 地理环境决定论 | 孟德斯鸠 | 地理环境决定社会制度 | 夸大地理环境，否认生产方式决定作用 |
| 人口决定论 | 马尔萨斯 | 人口规律决定社会 | 把自然规律套到社会上 |
| 社会达尔文主义 | 斯宾塞 | 社会=生物界，适者生存 | 用生物规律解释社会，为剥削辩护 |
| 历史循环论 | 维科、斯宾格勒、汤因比 | 历史循环、文明兴衰 | 否认社会发展是前进上升 |
| 历史虚无主义 | — | 否定历史规律、否定革命 | 唯心史观的政治表现 |
| 宿命论 | 奥古斯丁、加尔文（预定论） | 一切命中注定 | 否认人的能动性 |
| 唯意志论 | 叔本华、尼采 | 意志决定历史 | 夸大主观能动性 |
| 技术决定论 | — | 技术单向决定社会 | 忽视生产关系、制度和人的作用 |
| 抽象人性论 | 费尔巴哈、"真正的社会主义" | 人有永恒不变的本质 | 脱离社会关系谈人 |
| 社会契约论/天赋人权论 | 霍布斯、洛克、卢梭 | 国家源于契约、权利天赋 | 抽象人性论，掩盖国家阶级本质 |

## 5. 政治经济学批判

| 主义/流派 | 人物 | 主张 | 马原批判/态度 |
|---|---|---|---|
| 重商主义 | 托马斯·孟 | 财富=金银，追求顺差 | 只看流通，不懂生产 |
| 重农主义 | 魁奈、杜尔哥 | 农业是唯一生产部门 | 片面，但《经济表》有贡献 |
| 古典政治经济学 | 亚当·斯密、大卫·李嘉图 | 劳动价值论、"看不见的手" | **批判继承**：劳动价值论合理，但混同价值与价格、掩盖剥削 |
| 庸俗政治经济学 | 萨伊、马尔萨斯、巴师夏、西尼尔 | 萨伊定律、三位一体公式、经济和谐论、节欲论 | 为资本主义辩护，掩盖剩余价值来源 |
| 空想社会主义 | 圣西门、傅立叶、欧文 | 设计理想社会 | **批判继承**：揭露矛盾，但不懂历史规律、找不到依靠力量 |
| 小资产阶级社会主义 | 西斯蒙第、蒲鲁东 | 退回小生产、反对大工业 | 开历史倒车 |
| 无政府主义 | 蒲鲁东、巴枯宁、克鲁泡特金 | 废除国家与权威 | 否认无产阶级专政 |
| 拉萨尔主义 | 拉萨尔 | "铁的工资规律"、国家帮助合作社 | 马克思《哥达纲领批判》批判 |
| 杜林主义 | 杜林 | 先验哲学 + 庸俗经济学 | 恩格斯《反杜林论》批判 |
| 伯恩施坦修正主义 | 伯恩施坦 | "运动就是一切，最终目的微不足道" | 放弃革命、改良主义 |
| 考茨基主义 | 考茨基 | "超帝国主义论" | 机会主义、背叛革命 |
| 民主社会主义 | 伯恩施坦、社会民主党 | 议会道路、福利国家 | 改良主义，不是科学社会主义 |
| 凯恩斯主义 | 凯恩斯 | 国家干预、有效需求 | 治标不治本，不能消除基本矛盾 |
| 新自由主义 | 哈耶克、弗里德曼 | 私有化、市场化、自由化 | 资本逻辑的意识形态 |
| 经济浪漫主义 | 西斯蒙第 | 回到小生产 | 反历史 |

## 8. 不是全盘否定：批判继承（必背）

| 对象 | 继承什么（合理内核） | 批判什么 |
|---|---|---|
| 黑格尔 | 辩证法合理内核 | 客观唯心体系、"绝对精神" |
| 费尔巴哈 | 唯物主义基本内核 | 形而上学、直观、唯心史观、抽象人性论 |
| 古典政治经济学 | 劳动价值论 | 掩盖剥削、混同价值与价格 |
| 空想社会主义 | 揭露资本主义、设想未来 | 不懂历史规律、找不到阶级力量 |
| 法国唯物主义 | 唯物论 | 机械性、唯心史观 |
| 达尔文进化论 | 生物进化 | 不能直接套用社会（社会达尔文主义） |
| 自然科学三大发现 | 细胞、能量守恒、进化论 | 为辩证唯物论提供科学基础 |
