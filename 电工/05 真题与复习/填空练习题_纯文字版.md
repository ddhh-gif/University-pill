# 电工电子技术复习资料 — 一、填空练习题（纯文字版）

> 来源：`电工电子技术复习资料全.pdf` 第 1–2 页。横线上为原资料给出的答案；原卷未填或原文模糊处用「（原卷未填：……）」注明。

1、正弦电压和电流统称为正弦量，正弦量的特征分别用 **幅值**、**角频率** 和 **初相位** 来表示。

2、晶体三极管是由 **三** 个电极、**两** 个 PN 结组成的，按结构不同可分为 **NPN** 型和 **PNP** 型两大类。

3、理想电压源具有两个基本特征，其一是它的端电压 **为定值 US 或为一定的时间函数 u(t)=f(t)** 与 **流过的电流** 无关。

4、理想运放工作在线性区，具有两个重要特点：
①、理想运放同相输入端和反相输入端电位近似相等，即 U- = U+，称为 **虚短**；
②、理想运放同相输入端和反相输入端的输入电流等于零，即 I- = I+ = 0，称为 **虚断**。

5、鼠笼型三相异步电动机的起动方法有 **直接起动** 和 **降压起动** 两种。Y/Δ 换接起动属于 **降压** 起动。所谓 Y/Δ 换接起动就是把正常工作时作 **三角** 形联接的定子绕组，在起动时接成 **星** 形，待转速上升到接近额定转速时，再换接成 **三角** 形。

6、正弦电压和电流统称为正弦量，正弦量的特征分别用 **幅值**、**角频率** 和 **初相位** 来表示。
（注：与第 1 题重复，原资料如此。）

7、逻辑函数 F = A ⊕ B，它的与或表达式为 F = **A·B′ + A′·B**（即 A 非与 B 或 A 与 B 非；原资料此空未填）。
（注：原资料编号重复，此条与下一条在原文中均编号为 7。）

7（补）、三相交流发电机产生的三相对称电动势，相序 A-B-C-A，已知 A 相电动势为 eA = Em·sin(ωt + 120°)，则 eB = **Em·sin ωt**，eC = **Em·sin(ωt − 120°)**。

8、我国工频电网供电的周期 T 是 **20** ms，频率 f 是 **50** Hz，角频率 ω 是 **314** rad/s。

9、点接触型二极管 PN 结面积较小，允许通过的电流小，但它的等效结电容小，适用于 **高频（高频小信号）** 和 **开关（检波）** 工作（原资料此两空未填，括号内为参考）。面接触型二极管 PN 结面积大，允许通过的电流大，但相应等效结电容也大，一般用于 **低频整流**。

10、分析异或门逻辑关系，当两个输入端相同时输出为 **“0”**，当两个输入端不同时输出为 **“1”**。

11、逻辑函数 F = A′B + AB′ 表示的逻辑关系为 **异或**（原资料印作“同或”，实为异或；AB + A′B′ 才是同或）。

12、晶体三极管输出特性曲线族可分为三个工作区，① **截止区**、② **放大区**、③ **饱和区**。

13、阻容耦合放大器输入端的电容 C1 是为了使放大器的静态工作点不受 **信号源** 的影响；输出端电容 C2 是为了使静态工作点不受 **负载** 的影响，并保证只有交流传输。
