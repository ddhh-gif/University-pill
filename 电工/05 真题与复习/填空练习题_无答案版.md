# 电工电子技术复习资料 — 一、填空练习题（无答案版）

1、正弦电压和电流统称为正弦量，正弦量的特征分别用 __________、__________ 和 __________ 来表示。

2、晶体三极管是由 __________ 个电极、__________ 个 PN 结组成的，按结构不同可分为 __________ 型和 __________ 型两大类。

3、理想电压源具有两个基本特征，其一是它的端电压 __________ 与 __________ 无关。

4、理想运放工作在线性区，具有两个重要特点：
①、理想运放同相输入端和反相输入端电位近似相等，即 U- = U+，称为 __________；
②、理想运放同相输入端和反相输入端的输入电流等于零，即 I- = I+ = 0，称为 __________。

5、鼠笼型三相异步电动机的起动方法有 __________ 和 __________ 两种。Y/Δ 换接起动属于 __________ 起动。所谓 Y/Δ 换接起动就是把正常工作时作 __________ 形联接的定子绕组，在起动时接成 __________ 形，待转速上升到接近额定转速时，再换接成 __________ 形。

6、正弦电压和电流统称为正弦量，正弦量的特征分别用 __________、__________ 和 __________ 来表示。

7、逻辑函数 F = A ⊕ B，它的与或表达式为 F = __________。

8、三相交流发电机产生的三相对称电动势，相序 A-B-C-A，已知 A 相电动势为 eA = Em·sin(ωt + 120°)，则 eB = __________，eC = __________。

9、我国工频电网供电的周期 T 是 __________ ms，频率 f 是 __________ Hz，角频率 ω 是 __________ rad/s。

10、点接触型二极管 PN 结面积较小，允许通过的电流小，但它的等效结电容小，适用于 __________ 和 __________ 工作。面接触型二极管 PN 结面积大，允许通过的电流大，但相应等效结电容也大，一般用于 __________。

11、分析异或门逻辑关系，当两个输入端相同时输出为 __________，当两个输入端不同时输出为 __________。

12、逻辑函数 F = A′B + AB′ 表示的逻辑关系为 __________。

13、晶体三极管输出特性曲线族可分为三个工作区，① __________、② __________、③ __________。

14、阻容耦合放大器输入端的电容 C1 是为了使放大器的静态工作点不受 __________ 的影响；输出端电容 C2 是为了使静态工作点不受 __________ 的影响，并保证只有交流传输。
