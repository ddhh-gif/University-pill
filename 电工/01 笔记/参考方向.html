电路分析 · 参考方向

先定方向，
再让读数带符号。

电路图上的箭头和正负号，大多不是电路自带的属性，而是你落笔前先立下的约定。约定一换，读数就变号——但电阻的发热、灯泡的亮度，一点都没变。

一个回路 两处约定 三种符号
看这道例题 → 先分清三件事
同一股电流 · 两个约定 参考方向 →
+2.00 A
按“向右”读出的电流
物理不变：向右 2.00 A

先分清三件事

实际方向、参考方向、读数

把它们混在一起，符号就一定会乱。分开看，每一步都只有一件事要做。

事实 / PHYSICAL

实际方向

电荷真正的流向，客观存在且唯一。它从不因为你怎么画而改变。

约定 / CONVENTION

参考方向

你在图上画的箭头和 + / −，是列方程前自己定的坐标轴。选哪边都行，选反了也不算错。

代数 / ALGEBRA
+2.00−2.00

读数

同向取正、反向取负。负号不是“负电流”，而是提醒你：真实方向和你的约定相反。

例题 / ONE LOOP

一条回路，两套约定

12 V 电源串联 2 Ω 和 4 Ω。物理事实只有一条：顺时针 2 A。下面你只改“怎么标”，不改“怎么流”。

参考方向与实际一致 参考方向与实际相反
物理事实：I = 2.00 A（顺时针），R₁ 上左端电位更高
电流参考方向
R₁ 电压参考极性
参考电流 I+2.00 A
R₁ 参考电压 U₁+4.00 V
参考方向关系关联 · 电流从 + 端流入
R₁ 功率 P（按吸收算）+8.00 W

“关联”到底在说什么？

功率怎么算 P = U₁·I = (+4.00)(+2.00) = +8.00 W 吸收
KVL（这里让绕行方向 = 电流参考方向） 2I + 4I − 12 = 0 ⇒ I = +2.00 A

绕行方向为什么能这样选？

实际电压：左端比右端高 4.00 V（左 +）。实际功率：R₁ 永远吸收 8.00 W，电源放出 24.00 W，R₂ 吸收 16.00 W。
为什么电源项有时写 −12，有时写 +12？

本例里让绕行方向始终跟着电流参考方向走。于是电阻项永远是 +RI，符号只由电源项决定。

顺时针：依次走过 R₁、R₂，电流与绕行同向，记 +2I、+4I。走过电源时从 − 端到 + 端，电位升高 12 V，写成“电压降”就是 −12。得 2I + 4I − 12 = 0，I = +2 A。

逆时针：电阻项仍是 +2I、+4I；电源改为从 + 端到 − 端，写成电压降是 +12。得 2I + 4I + 12 = 0，I = −2 A。

两式说的是同一股物理电流：顺时针 2 A。第二式的负号，只是“参考方向取反”的记账。

功率账本 / POWER BALANCE

为什么电阻写 +8 W，电源写 −24 W？

统一按“吸收”来记账：P 为正就是真吸收；P 为负就说明它在放出。

电源 U_s放出
−24.00 W
P_s = −U_s·I = −(12)(+2.00) = −24.00 W
负号 = 按“吸收”记账为负 ⇒ 实际在放出 24.00 W。
R₁ = 2 Ω吸收
+8.00 W
P₁ = I²R₁ = 2² × 2 = 8.00 W
电阻永远吸收，所以吸收功率恒为正。
R₂ = 4 Ω吸收
+16.00 W
P₂ = I²R₂ = 2² × 4 = 16.00 W
8 W + 16 W = 24 W，正好等于电源放出的功率。
放出
电源 24 W
吸收
R₁ 8 W R₂ 16 W

口诀：先按“吸收”算 P；P > 0 吸收（记 +），P < 0 放出（记 −）。电阻的吸收功率恒正；电源算成负的，就是在放出。换参考方向只会换算法，不会换结论。

补充 / LOOP ARROW

列 KVL 时，那个绕圈的箭头是什么？

它叫绕行方向：写回路方程前，你先选定“沿着哪一边绕一圈”，作为给各项定正负的尺子。它不是电流的真实方向，也不是电流的参考方向——三件事可以互不相同。

独立的约定 · 与参考电流无关
绕行方向（只影响 KVL 写法）

橙色虚线箭头是电流参考方向（这里固定在顺时针）；紫色虚线圈是 KVL 绕行方向。两者各自独立，可以同向也可以反向。

它为什么必须存在？因为 KVL 说“沿任意闭合回路，电压降的代数和为零”——“沿哪个方向绕”就是你替这条回路选的正方向。

过电阻

绕行方向与电流参考方向 同向 → +RI；反向 → −RI。

过电源

绕行从 − 到 +（电位升高）→ 记为 −U_s；从 + 到 − → +U_s。

KVL（电流参考方向固定为顺时针） 沿顺时针：2I + 4I − 12 = 0 ⇒ I = +2.00 A

绕行方向与电流参考方向同向：电阻项取 +RI。

绕行方向整体反过来，方程每一项都变号，但解出的 I 不变——只是换了个记账方向。为省事，常直接让绕行方向 = 电流参考方向，此时电阻项全是 +RI（主例题就是这么做的）。回到主例题

概念澄清 / CONVENTIONS

关联、参考极性、电源极性：谁能随便设？

先把三样东西分开：实际方向、你画的参考方向、元件给定的极性。混在一起，符号就会打架。

① “关联”是两套参考之间的关系，不是电流方向

判断只看参考方向：参考电流从电压的 + 端流入 → 关联；从 − 端流入（即从 + 端流出）→ 非关联。

它和真实电流往哪流无关。下面四种画法都合法，读数各不相同，但 R₁ 永远吸收 8 W。

还要分清：无源元件的电压 +/− 是人定的参考极性；参考节点 / 地 也是人选的 0 V，换它只让所有节点电位平移，不改变电压差。

网页里的“关联 · 参考电流从 + 端流入”，检查的是这两个参考约定，而不是在描述实际电流。
R₁ 的四种画法 · 物理事实：电流向右 2 A，左端高 4 V
参考 IU₁ 的 +关系读数 U₁ / IP吸收
→ 右左端关联+4 V / +2 A+8 W
← 左左端非关联+4 V / −2 A+8 W
→ 右右端非关联−4 V / +2 A+8 W
← 左右端关联−4 V / −2 A+8 W

你可以自由设定

  • 支路电流参考箭头改了，读数整体变号
  • 无源元件的电压 +/−改了，U 变号；元件律的写法要跟着改
  • KVL 绕行方向改了，方程整体变号，解不变
  • 参考节点 / 地改了，只让所有节点电位平移，电压差不变

不能单独改

  • 电源的 +/− 与 U_s成对固定：把 + 挪位，U_s 必须同时变号
  • 受控源控制量的参考方向属于模型；单独翻箭头，等于换了一道题

但流过电源的电流参考箭头仍然自由；它只决定用 P = UI 还是 P = −UI。

电源的极性为什么“给定”

理想电压源的 +/− 和 U_s 是同一个模型参数的两面：+ 在上、U_s = 12 V 表示 V上 − V下 = 12 V。把 + 挪到下边却不把 U_s 改成 −12 V，描述的就已经是另一个源了。

不过电流参考箭头仍由你定。两种画法算出的“吸收功率”都是 −24 W ⇒ 实际放出 24 W：

电流参考 ↑（离开 +）· 非关联P = −U_s·I = −12 × 2 = −24 W
电流参考 ↓（进入 +）· 关联P = U_s·I = 12 × (−2) = −24 W

公式变了，结论不变：电源放出 24 W。

一句话：电流箭头自由；无源元件的电压极性自由；电源的电压极性与数值给定；“关联”只决定用 P = UI 还是 P = −UI，不改变物理功率。

读法 / SIGN → DIRECTION

看到 −2.00 A，先翻译方向

负号不是“电流是负的”。电流的大小永远为正，负号只描述方向与你画的箭头相反。

你写的约定
−2.00 A

参考箭头向左，读数是负的。

转 180°
物理的事实
2.00 A →

大小取绝对值，方向沿参考方向转 180°。

01

读数的绝对值，就是电流的真实大小。

02

读数为负，就把参考箭头转 180°，得到实际方向。

03

实际方向和你画的箭头一致时，读数为正，不用转。

同样的翻译用在功率上：电源支路的 P = −24 W（按“吸收”算），负号表示它其实在放出 24 W。所以口诀是：P > 0 吸收，P < 0 放出。

四个箭头，四份约定

原题 · 参考方向已标出

上一题里你标了四份约定：I₁ ↑、U₂ 上 + 下 −、0.1U₂ ←、2I₁ 上 + 下 −。

设 U_s > 0，解出 I₁ = U_s/16 > 0，说明实际方向和箭头一致；U₂ = −U_s/8 < 0，说明实际极性和你标的上 + 下 − 相反——实际是下 + 上 −。

但 U₂ = −2I₁ 这个关系，是在你选的这组参考方向下成立的。负号属于“约定 vs 事实”，不是方程算错了。

一个容易踩的坑：受控源里的 I₁、U₂ 是控制量。参考方向是受控源模型的一部分——只改箭头、不改受控源的符号，等于换了一道题。

按你标的参考方向读出：U₂ = −U_s/8 < 0（设 U_s > 0）。 翻译：实际极性是 下 + 上 −；大小 |U₂| = U_s/8。

带走这四条

符号不是猜的，是记出来的。

01

先假设，再列式。箭头画在哪边都不算错，画完就别中途偷偷改。

02

同向取正，反向取负。算出负号，就把实际方向翻译成箭头的反方向。

03

关联 P = UI，非关联 P = −UI。P > 0 吸收，P < 0 放出。

04

受控源的控制量也有参考方向。它是模型的一部分，不能单独翻。

参考方向，是你动笔前替电路签的一份协议。
