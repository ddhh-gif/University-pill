利用欧拉公式 $e^{j\theta} = \cos\theta + j\sin\theta$，我们可以把正弦量 $A\sin(\omega t + \phi)$ 看作旋转矢量 $A e^{j(\omega t + \phi)}$ 的虚部。

**推导三个关键变换规则：**

1. **正弦量 $\rightarrow$ 相量（去掉时间因子 $e^{j\omega t}$）**

   * 时域：$i(t) = I_m \sin(\omega t + \phi_i)$
   * 相量：$\dot{I} = I_m \angle \phi_i$ （或者写成 $I_m e^{j\phi_i}$）
   * *记忆：只保留振幅和初相位。*

2. **微分 $\rightarrow$ 乘以 $j\omega$**

   * 时域：$\frac{d}{dt} [I_m e^{j(\omega t + \phi)}] = j\omega \cdot I_m e^{j(\omega t + \phi)}$
   * 相量域：$\frac{d}{dt} \rightarrow j\omega$
   * *记忆：求导就是乘以 $j\omega$。*

3. **积分 $\rightarrow$ 除以 $j\omega$**

   * 时域：$\int [I_m e^{j(\omega t + \phi)}] dt = \frac{1}{j\omega} \cdot I_m e^{j(\omega t + \phi)}$
   * 相量域：$\int dt \rightarrow \frac{1}{j\omega}$
   * *记忆：积分就是除以 $j\omega$。*

### 三、 推导元件的“阻抗”（Impedance）

利用上面的规则，把微分方程变成代数方程：

原方程：$u = R i + L \frac{di}{dt} + \frac{1}{C} \int i dt$

变成相量形式（$\dot{U}$ 和 $\dot{I}$）：
$$ \dot{U} = R \dot{I} + L (j\omega \dot{I}) + \frac{1}{C} (\frac{1}{j\omega} \dot{I}) $$
提取公因式 $\dot{I}$：
$$ \dot{U} = [ R + j\omega L + \frac{1}{j\omega C} ] \dot{I} $$

定义括号里的部分为**总阻抗 $Z$**：
$$ Z = R + j(X_L - X_C) $$
其中：

* 电阻 $R$：实部。
* 感抗 $X_L = \omega L$（对应 $j\omega L$）。
* 容抗 $X_C = \frac{1}{\omega C}$（对应 $\frac{1}{j\omega C} = -j \frac{1}{\omega C}$）。

| 元件 | 时域关系     | 阻抗 $Z=\dot{U}/\dot{I}$ | 电压相对电流    |
|:---- |:------------ |:------------------------ |:--------------- |
| 电阻 | $v=Ri$       | $R$                      | 同相            |
| 电感 | $v=L\,di/dt$ | $j\omega L$              | 超前 $90^\circ$ |
| 电容 | $i=C\,dv/dt$ | $1/(j\omega C)$          | 滞后 $90^\circ$ |

**结论：欧姆定律 $\dot{U} = \dot{I} Z$ 在交流电中依然成立，只是变成了复数运算！**

### 四、 结合图片【例 4.6.1】的完整解题流

现在你看书上的解题过程，其实就是上面推导的逆过程。

**题目数据**：$R=100, L=0.3, C=40\mu F, \omega=500$。
电压 $u(t) = 100\sqrt{2} \sin(500t + 30^\circ)$。

#### 第一步：准备“武器”（算阻抗）

书上先算了 $X_L$ 和 $X_C$：

* $X_L = \omega L = 500 \times 0.3 = 150 \, \Omega$
* $X_C = \frac{1}{\omega C} = \frac{1}{500 \times 40 \times 10^{-6}} = 50 \, \Omega$
* 总阻抗 $Z = R + j(X_L - X_C) = 100 + j(150 - 50) = 100 + j100$。
* 把 $Z$ 变成极坐标（为了做除法）：$Z = \sqrt{100^2+100^2} \angle \arctan(1) = 141.4 \angle 45^\circ \, \Omega$。

#### 第二步：时域 $\rightarrow$ 频域（电压变相量）

* 电压有效值 $U = 100$ V（注意题目给的是 $100\sqrt{2}$，这是最大值，有效值是100。书上写的 $\dot{U}=100\angle 30^\circ$ 用的是有效值相量）。
* $\dot{U} = 100 \angle 30^\circ$ V。

#### 第三步：频域计算（核心代数运算）

利用欧姆定律求电流相量 $\dot{I}$：
$$ \dot{I} = \frac{\dot{U}}{Z} = \frac{100 \angle 30^\circ}{141.4 \angle 45^\circ} $$

* **模相除**：$100 / 141.4 \approx 0.707$ A。
* **角相减**：$30^\circ - 45^\circ = -15^\circ$。
* 结果：$\dot{I} = 0.707 \angle -15^\circ$ A。

#### 第四步：求各元件电压（频域）

* 电阻电压 $\dot{U}_R = \dot{I} R = (0.707 \angle -15^\circ) \times 100 = 70.7 \angle -15^\circ$ V。（电阻电压与电流同相）
* 电感电压 $\dot{U}_L = \dot{I} (j X_L) = (0.707 \angle -15^\circ) \times (150 \angle 90^\circ) = 106 \angle 75^\circ$ V。（电感电压超前电流90度，即角度+90）
* 电容电压 $\dot{U}_C = \dot{I} (-j X_C) = (0.707 \angle -15^\circ) \times (50 \angle -90^\circ) = 35.35 \angle -105^\circ$ V。（电容电压滞后电流90度，即角度-90）

#### 第五步：频域 $\rightarrow$ 时域（写回正弦表达式）

把算出来的相量变回 $sin$ 函数。

* 电流 $i(t) = 0.707\sqrt{2} \sin(500t - 15^\circ) = 1 \sin(500t - 15^\circ)$ A。（注意如果要写瞬时值，通常要把有效值乘回 $\sqrt{2}$ 变回最大值，除非题目只要有效值表达式）。
  * *注：书上最后写的 $i = 0.707 \angle -15^\circ$ 是相量，如果要写瞬时值 $i(t)$，需写成 $\sin$ 形式。*
