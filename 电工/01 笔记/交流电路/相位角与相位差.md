# 相位角
### 一、 时域定义（基于时间波形）

假设有两个同频率的正弦交流量，电压 $u(t)$ 和电流 $i(t)$，它们的标准数学表达式为：
*   $u(t) = U_m \sin(\omega t + \varphi_u)$
*   $i(t) = I_m \sin(\omega t + \varphi_i)$

其中，$(\omega t + \varphi_u)$ 和 $(\omega t + \varphi_i)$ 称为它们的**相位**，而 $\varphi_u$ 和 $\varphi_i$ 称为**初相位**。

**相位角 $\varphi$ 的定义为：电压的初相位减去电流的初相位。**
$$ \varphi = \varphi_u - \varphi_i $$

**物理意义（时间差）：**
相位角本质上反映了两个波形在时间轴上达到最大值（或过零点）的**时间差 $\Delta t$**。
$$ \Delta t = \frac{\varphi}{\omega} $$
*   若 $\varphi > 0$：电压比电流**先**达到最大值，称**电压超前电流** $\varphi$ 角。
*   若 $\varphi < 0$：电压比电流**后**达到最大值，称**电压滞后电流** $|\varphi|$ 角。
*   若 $\varphi = 0$：电压和电流同时达到最大值，称**电压与电流同相**。

---

### 二、 频域定义（基于相量与阻抗）

在工程计算中，我们更常用复数（相量）来分析电路。根据欧姆定律的相量形式：$\dot{U} = \dot{I} \cdot Z$

电路的**复阻抗** $Z$ 可以表示为代数形式或极坐标形式：
$$ Z = R + jX = |Z| \angle \varphi $$

**相位角 $\varphi$ 的定义为：复阻抗 $Z$ 的辐角。**
$$ \varphi = \arctan \left( \frac{X}{R} \right) = \arctan \left( \frac{\text{电抗}}{\text{电阻}} \right) $$
*(注：这就是你图片中手写笔记标注的公式 $\varphi = \arctan \frac{X_L - X_C}{R}$ 的来源)*

**物理意义（功率特性）：**
相位角 $\varphi$ 直接决定了电路的**功率因数**（$\cos\varphi$）。
*   $\cos\varphi$ 表示电源发出的视在功率中有多少转化为有用的有功功率。
*   $\varphi$ 的绝对值越大，无功功率占比越大，电能利用率越低。

---

### 三、 基本电路元件的相位角

要理解复杂电路的相位角，必须先记住三个基本元件的“性格”：

| 元件 | 电压与电流关系 | 相位角 $\varphi$ | 物理本质 | 记忆口诀 |
| :--- | :--- | :---: | :--- | :--- |
| **纯电阻 (R)** | $u = iR$ | **$0^\circ$** | 消耗能量，无储能，电压电流同步变化。 | 同相 |
| **纯电感 (L)** | $u = L \frac{di}{dt}$ | **$+90^\circ$** | 阻碍电流变化。电流想变，电感产生反向电压，导致电压“跑”在电流前面。 | **E**LI (Voltage **E** leads **I** in **L**) |
| **纯电容 (C)** | $i = C \frac{du}{dt}$ | **$-90^\circ$** | 必须先有电压建立电场，才能充电产生电流（或者理解为电流先流入才能建立电压）。 | **I**CE (**I** leads **E** in **C**) |

*(注：另一个经典口诀是 **CIVIL**：在 **C** (电容) 中，**I** (电流) 超前 **V** (电压)；在 **L** (电感) 中，**V** (电压) 超前 **I** (电流)。)*

---

### 四、 RLC 组合电路的相位角判定

在实际电路中，R、L、C 组合在一起，总相位角由**电抗的代数和**决定：

#### 1. 串联电路
$$ \varphi = \arctan \left( \frac{X_L - X_C}{R} \right) = \arctan \left( \frac{\omega L - \frac{1}{\omega C}}{R} \right) $$
*   **感性电路**：若 $X_L > X_C$，则 $\varphi > 0$，电压超前电流（整体表现得像电感）。
*   **容性电路**：若 $X_L < X_C$，则 $\varphi < 0$，电压滞后电流（整体表现得像电容）。
*   **阻性电路（谐振）**：若 $X_L = X_C$，则 **$\varphi = 0$**，电压电流同相。

#### 2. 并联电路
并联电路通常用**导纳** $Y = \frac{1}{Z} = G + jB$ 来分析（$G$ 为电导，$B$ 为电纳）。
$$ \varphi = -\arctan \left( \frac{B}{G} \right) = -\arctan \left( \frac{B_C - B_L}{G} \right) $$
*(注意负号：因为阻抗角和导纳角互为相反数)*
*   若 $B_C > B_L$ (容性电纳大)，$\varphi < 0$，电压滞后电流。
*   若 $B_C < B_L$ (感性电纳大)，$\varphi > 0$，电压超前电流。

### 五、 相位角与“谐振”的终极联系

回到你最初的问题，为什么谐振如此重要？

**谐振的严格定义就是：通过调节频率 $\omega$ 或元件参数 $L, C$，强制使电路的总相位角 $\varphi = 0$。**

当 $\varphi = 0$ 时，会发生以下连锁反应：
1.  **数学上**：$\tan\varphi = 0 \Rightarrow X_L - X_C = 0 \Rightarrow \omega L = \frac{1}{\omega C}$。
2.  **阻抗上**：$Z = R + j0 = R$，虚部消失，阻抗模值达到极值（串联最小，并联最大）。
3.  **功率上**：功率因数 $\cos\varphi = \cos(0) = 1$。电源发出的所有能量都被电阻消耗，电感和电容之间自己“内部消化”无功功率，不再向电源索取无功功率。

**总结：** 相位角 $\varphi$ 是交流电路的“方向盘”。它告诉你电路当前是偏向电感（超前）、偏向电容（滞后），还是处于完美的平衡状态（谐振，同相）。
### 一、 串联谐振 (Series Resonance)

#### 1. 谐振条件的本质
*   **阻抗角度：** 复阻抗 $Z = R + j(\omega L - \frac{1}{\omega C})$。当虚部为零，即 $\text{Im}[Z] = 0$ 时发生谐振。
*   **相位角度：** 电压 $\dot{U}$ 与电流 $\dot{I}$ 同相，功率因数 $\cos\varphi = 1$。
*   **频率公式：** $\omega_0 = \frac{1}{\sqrt{LC}}$，$f_0 = \frac{1}{2\pi\sqrt{LC}}$。

#### 2. 谐振时的特征（补充能量视角）
*   **电压关系：** $U_L = U_C = Q U$。若 $Q \gg 1$，则电感和电容上会出现**过电压**，可能击穿元件（这是串联谐振在电力系统中要避免，但在电子电路中要利用的）。
*   **能量振荡（书上未讲）：**
    *   在谐振时，电源只提供电阻消耗的能量（有功功率）。
    *   电感中的磁场能量 $W_L$ 和电容中的电场能量 $W_C$ 互相交换。
    *   总储能 $W = W_L + W_C$ 保持恒定（理想情况下），能量在 L 和 C 之间以 $\omega_0$ 的频率振荡，不与电源交换无功功率。

#### 3. 频率特性与通频带 (Bandwidth) —— 重要考点
书上画了曲线，但没讲定量计算。
*   **电流频率特性：** $I(\omega) = \frac{U}{\sqrt{R^2 + (\omega L - \frac{1}{\omega C})^2}}$。
*   **通频带 (BW)：** 指电流下降到最大值的 $\frac{1}{\sqrt{2}}$ (即 0.707倍) 时所对应的频率范围。
    *   公式：$BW = \omega_2 - \omega_1 = \frac{\omega_0}{Q}$ (或者 $\Delta f = \frac{f_0}{Q}$)。
*   **选择性：** $Q$ 值越大，通频带越窄，曲线越尖锐，电路从众多频率信号中选出特定频率信号的能力（选择性）越强。

### 二、 并联谐振 (Parallel Resonance) —— 书上可能未详细展开

这是与串联谐振对应的另一大类，必须掌握。

#### 1. 理想 RLC 并联电路
*   **模型：** R、L、C 三者并联。
*   **导纳：** $Y = \frac{1}{R} + j(\omega C - \frac{1}{\omega L}) = G + jB$。
*   **谐振条件：** 电纳 $B=0$，即 $\omega C = \frac{1}{\omega L} \Rightarrow \omega_0 = \frac{1}{\sqrt{LC}}$。
*   **特征：**
    *   **阻抗最大：** $|Z|_{max} = R$（纯电阻性）。
    *   **电流最小：** 总电流 $I = U/R$ 达到最小值。
    *   **电流谐振：** 电感支路电流 $I_L$ 和电容支路电流 $I_C$ 大小相等、相位相反，互相抵消。且 $I_L = I_C = Q I_{total}$。若 $Q$ 很大，支路电流远大于总电流（过电流现象）。

#### 2. 实际线圈与电容并联 (工程最常用模型)
实际电感线圈有电阻 $R$，不能视为理想电感。
*   **模型：** 一个实际线圈（$R$ 与 $L$ 串联）与电容 $C$ 并联。
*   **阻抗：** $Z = \frac{(R+j\omega L) \cdot \frac{1}{j\omega C}}{R + j\omega L + \frac{1}{j\omega C}}$。
*   **谐振条件：** 令阻抗的虚部为零。
    *   推导得出：$\omega_0 L = \frac{1}{\omega_0 C} \sqrt{1 - (\frac{R}{\omega_0 L})^2}$ (近似计算时，若 $R \ll \omega L$，则仍约为 $\frac{1}{\sqrt{LC}}$)。
*   **特征：** 谐振时阻抗呈纯电阻性，且达到最大值 $Z_0 \approx \frac{L}{RC} = Q^2 R$。

---

### 三、 品质因数 Q 的物理意义 (通用)

书上只给了公式，这里补充物理本质：
$$Q = 2\pi \times \frac{\text{谐振时电路储存的最大能量}}{\text{一个周期内电路消耗的能量}}$$
*   **串联时：** $Q = \frac{\omega_0 L}{R} = \frac{1}{R}\sqrt{\frac{L}{C}}$ （电阻越小，Q越大，损耗越小）。
*   **并联时：** $Q = \frac{R}{\omega_0 L} = R\sqrt{\frac{C}{L}}$ （电阻越大，Q越大，分流损耗越小）。

### 四、 非正弦周期电流电路 (对应图片左上角习题 4.10)

图片左上角出现了 $u_1 = 10\sin(1000t) + 2\sin(2000t)$，这属于**非正弦周期电路**，需要用**谐波分析法**。

#### 1. 核心思想：叠加定理
非正弦周期信号可以分解为直流分量和一系列不同频率的正弦谐波（傅里叶级数）。
*   **步骤：**
    1.  将电源分解为直流、基波、二次谐波等。
    2.  **分别计算**：
        *   **直流作用时：** 电感短路 ($X_L=0$)，电容开路 ($X_C=\infty$)。
        *   **基波 ($\omega$) 作用时：** 计算 $X_{L1} = \omega L, X_{C1} = 1/(\omega C)$。
        *   **n次谐波 ($n\omega$) 作用时：** 感抗变大 ($n X_L$)，容抗变小 ($X_C/n$)。
    3.  **瞬时值叠加**：将各次谐波计算出的电压/电流瞬时值相加（注意：有效值不能直接相加，要用平方和开根号；相量不能直接相加，因为频率不同）。

#### 2. 针对图中习题 4.10.2 的解析思路
*   输入 $u_1$ 包含 $\omega_1=1000$ 和 $\omega_2=2000$ 两个分量。
*   这是一个 RC 或 RLC 电路。
*   **对于 1000 rad/s：** 计算阻抗 $Z_1$，利用分压公式求输出 $u_{2}'$。
*   **对于 2000 rad/s：** 频率变了，容抗 $X_C$ 减半，感抗 $X_L$ 加倍。重新计算阻抗 $Z_2$，求输出 $u_{2}''$。
*   **最终结果：** $u_2(t) = u_{2}'(t) + u_{2}''(t)$。

### 五、 总结对比表

| 特性 | 串联谐振 | 并联谐振 (理想) | 实际线圈与C并联 |
| :--- | :--- | :--- | :--- |
| **条件** | $\omega L = 1/(\omega C)$ | $\omega C = 1/(\omega L)$ | 虚部为0 (近似同左) |
| **阻抗** | **最小** ($Z=R$) | **最大** ($Z=R$) | **最大** ($Z \approx L/RC$) |
| **电流** | **最大** ($I=U/R$) | **最小** ($I=U/R$) | **最小** |
| **电压/电流关系** | $U_L=U_C=QU$ (过电压) | $I_L=I_C=QI$ (过电流) | 支路电流约为总电流Q倍 |
| **应用** | 电压源选频、收音机输入级 | 电流源选频、振荡器 | 无线电接收机调谐回路 |

这个整理涵盖了从基础定义到工程应用，再到习题解法的完整逻辑链条。
